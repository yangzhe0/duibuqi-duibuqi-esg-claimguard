# Data Card

## 数据来源

数据来源为巨潮资讯网（CNINFO）。

## 检索关键词

采集过程围绕以下关键词和主题进行检索与筛选：

- ESG报告
- 可持续发展报告
- 社会责任报告
- 环境、社会及治理报告
- 环境、社会和公司治理报告

## 下载对象

下载对象为上市公司公开披露的 ESG 相关 PDF 文件。当前主索引中的每条记录均对应一个本地 PDF 文件，文件保存于 `data/raw_pdfs/`。

## 排除规则

主索引排除了以下类型记录：

- 下载失败记录。
- skipped 记录。
- 英文版报告。
- 公告摘要。
- 仅提示披露事项但不构成完整报告正文的公告文件。

## 候选库规模

- 候选 PDF 数量：200。
- 索引记录数：200。
- 公司去重数量：198。
- 股票代码去重数量：200。
- 来源分布：`cninfo: 200`。
- 报告类型分布：`ESG报告: 171`，`可持续发展报告: 18`，`ESG暨社会责任报告: 11`。
- 年份字段分布：`2025: 196`，`2026: 4`。

注意：`year` 字段可能是公告发布年份，不应直接等同于报告所属年份。

## report_index.csv 字段说明

- `id`：CNINFO 公告 ID。
- `stock_code`：股票代码。
- `company`：公司简称。
- `year`：从公告标题或公告记录中提取的年份字段，可能对应公告发布年份。
- `report_type`：规则化报告类型。
- `title`：清洗后的公告标题。
- `announcement_date`：公告日期。
- `source`：数据来源，当前为 `cninfo`。
- `source_url`：公告详情页链接。
- `pdf_url`：PDF 下载链接。
- `original_title`：原始公告标题。
- `original_adjunct_url`：原始附件路径。
- `original_pdf_filename`：原始 PDF 附件文件名。
- `normalized_filename`：规范化保存文件名。
- `local_path`：本地 PDF 路径。
- `file_sha256`：文件 SHA256。
- `file_size_bytes`：文件大小。
- `error`：错误信息；主索引中为空。

## 当前数据限制

当前 200 份 PDF 是原始候选报告库，不是训练集、测试集或最终实验集。

目前没有完成训练集/测试集划分。目前没有完成人工标注。目前没有完成内容级解析质量评估。文件级干净只说明文件存在、路径正确、下载无错误，不代表报告正文一定适合 ESG 信息抽取任务。

潜在限制包括：

- PDF 扫描质量差。
- 表格结构复杂。
- 正文与标题匹配度不足。
- 可能存在重复或近重复披露。
- 部分报告内容对指标抽取任务贡献有限。
