# 项目台账

更新时间：2026-07-01

本台账记录当前提交版项目结构、最终数据口径、保留文件和已清理内容。当前版本以“证据约束型 ESG 长文档结构化抽取”为主线，最终论文工程已统一放入 `latex/`，原 `latex_final/` 已删除。

## 1. 最终目标

项目面向 B 题“ESG 报告数据智能提取与分析：基于大模型的定量与定性指标识别”。系统从公开 ESG 类 PDF 报告出发，经过 PDF 结构化解析、内容块建模、ESG-65 指标体系、候选证据召回、大语言模型约束抽取、后处理和质量诊断，输出可复核的结构化结果。

项目不做 ESG 评分、企业排名或投资建议。found/missing/error 是运行结果分布，不是人工标注评价结论。

## 7. 论文工程

最终论文工程在 `latex/`：

- `latex/MathModel.tex`：论文源码，使用原始研究生数学建模模板
- `latex/MathModel.pdf`：最终 PDF
- `latex/gmcmthesis.cls`、`latex/fonts/`、`latex/image/`：原始竞赛模板类文件、字体和封面素材
- `latex/figures/`：论文图件，SVG/PNG 双格式
- `latex/tables/`：统计表和案例表
- `latex/figure_contracts.md`：图表契约
- `latex/figure_gallery.html`：图表浏览面板
- `latex/SELF_CHECK.md`：自查记录
- `latex/build.sh`：重新生成图表并编译论文

当前论文图表已拆分年份和市场口径，系统截图为真实页面截图，典型案例表已改为可读长表。
