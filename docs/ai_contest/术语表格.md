# 术语表（ESG ClaimGuard）

## 一、核心概念

| 中文名称 | 英文名称 | 缩写 | 定义 |
|---|---|---|---|
| 可持续披露一致性预审 | Sustainability Disclosure Consistency Pre-review | SDCP | 在正式发布或提交前，对报告内部声明、证据、数值关系和条款覆盖进行辅助核验 |
| 原子声明 | Atomic Claim | Claim | 可独立判断支持、矛盾或证据不足的最小披露单元 |
| 声明—证据约束图 | Claim–Evidence Constraint Graph | CECG | 连接声明、证据块、主体、期间和标准条款，并显式记录支持、矛盾和约束关系的图结构 |
| 最小证据集合 | Minimal Evidence Set | MES | 足以支持或反驳一条声明的最少原文块集合 |
| 独立人工测试集 | Independent Human Test Set | human test set | 与模型输出隔离、由人工独立标注并裁决的评测集合；本次提交未使用 |
| 故障注入基准 | ESG Fault Injection Benchmark | ESG-Inject | 在真实声明基础上注入已知错误、具有确定答案的测试集 |
| 预审工作底稿 | Pre-review Workpaper | Workpaper | 记录问题、证据、依据、处置动作、责任人和版本的可导出成果 |

## 二、声明字段

| 符号/字段 | 中文含义 | 英文名称 | 说明 |
|---|---|---|---|
| `s` / `subject` | 声明主体 | Subject | 集团、母公司、子公司、员工、供应商等 |
| `m` / `metric` | 规范化指标 | Metric | 例如温室气体排放总量 |
| `t` / `period` | 期间 | Reporting Period | 报告期、基准年、目标年 |
| `v` / `value` | 数值 | Value | 原始数值及归一化数值 |
| `u` / `unit` | 单位 | Unit | 原始单位及规范单位 |
| `scope` | 口径/范围 | Scope | 范围一/二、合并口径、境内/境外等 |
| `qualifier` | 限定词 | Qualifier | 实际、目标、累计、同比、估算等 |
| `evidence` | 原文证据 | Evidence | 页码、block_id、bbox 和逐字原文 |

## 三、图关系

| 关系 | 中文名称 | 定义 |
|---|---|---|
| `supports` | 支持 | 证据充分覆盖声明的关键字段 |
| `contradicts` | 矛盾 | 证据或另一声明与当前声明不能同时成立 |
| `same_metric` | 同指标 | 两条声明映射到同一规范化指标 |
| `part_of` | 部分—整体 | 子项属于某个总量或集合 |
| `derived_from` | 推导自 | 声明可由其他声明通过公式得到 |
| `governed_by` | 受条款约束 | 声明或议题对应某项披露规则/标准 |

## 四、核验标签

| 中文标签 | 英文标签 | 定义 |
|---|---|---|
| 已支持 | Supported | 证据支持声明，且主体、期间、数值、单位和口径一致 |
| 相矛盾 | Contradicted | 证据明确反驳声明，或报告内部存在不可解释冲突 |
| 证据不足 | Insufficient Evidence | 当前证据不足以支持或反驳，不等于声明为假 |
| 已披露 | Disclosed | 找到适用条款要求的披露内容 |
| 已说明不适用 | Not Applicable with Explanation | 报告明确给出不适用或省略原因 |
| 未找到说明 | Explanation Not Found | 系统没有找到披露或省略说明，必须人工判断 |

## 五、评价指标

| 中文指标 | 英文名称 | 定义/公式 |
|---|---|---|
| 字段级 F1 | Field-level F1 | 对主体、指标、期间、值、单位、范围分别计算 Precision 和 Recall 的调和平均 |
| 证据召回率@K | Evidence Recall@K | 前 K 个证据块中包含人工最小证据集合的声明比例 |
| 宏平均 F1 | Macro-F1 | 三个事实核验类别 F1 的算术平均，避免多数类掩盖少数类 |
| 期望校准误差 | Expected Calibration Error | ECE；预测概率与真实正确率的分箱差异 |
| Brier 分数 | Brier Score | 概率预测与真实标签之间的均方误差 |
| 风险—覆盖曲线 | Risk–Coverage Curve | 随系统拒答/交人工比例变化的剩余错误率曲线 |
| 单位时间期望风险削减 | Expected Risk Reduction per Unit Time | `p(issue) × severity / review_time` |
| 标注采集函数 | Acquisition Function | `uncertainty + lambda × diversity`，只用于数据标注队列 |

## 六、边界术语

| 禁止或慎用表述 | 统一表述 | 原因 |
|---|---|---|
| 识别企业造假/漂绿 | 发现披露内部矛盾或证据不足 | 项目没有外部事实源，不能判断企业真实行为 |
| 自动审计 | 一致性预审/辅助核验 | 不替代法定审计或鉴证 |
| 同行标准 | 语料出现率 | 未完成行业分组前不能称同行 |
| 模型置信度 | 未校准模型分数 | 校准前不具有错误概率语义 |
| 缺失即违规 | 未找到披露或说明，需人工判断 | 标准适用性和省略理由可能不同 |
