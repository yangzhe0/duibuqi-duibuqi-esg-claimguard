# ESG ClaimGuard 参赛作品简介

## 300 字以内正文

ESG ClaimGuard 面向可持续发展报告编制、合规与审阅场景，利用 MinerU 解析复杂版面，以 Qwen3.6 按 65 项指标抽取声明，并把结果绑定到页码、区块和原文证据。系统已在 200 份报告、10,528 页上形成 13,000 条唯一结果，其中 7,688 条为有证据披露、5,312 条为缺失候选、错误为 0；全部有证据结果通过原文精确匹配，定量结果同时记录直接值或推导过程。网页工作台支持总览、披露预审、证据复核、质量评测、金标准和报告接入。系统只提供可追溯的预审线索，不作企业评分，不替代人工审阅或法定鉴证。

> 口径说明：正文不含标题与本说明，少于 300 个汉字；本作品不把未经独立人工评测的 Precision、Recall 或 F1 作为成果声明。
