# 可信披露诊断台：产品与模型合同

> **状态：已废止（2026-08-09）。** 本文保留用于记录上一版设计，不再作为后续实现和比赛论证依据。否决原因与新模型合同见 [题目分析.md](./题目分析.md)。

## 1. 核心问题

将现有“批量抽取后逐条浏览”的项目，重构为面向 ESG 编制人员、审阅人员和研究人员的可执行工作流：系统不仅给出抽取结果，还必须回答“下一条最值得人工核验的内容是什么、为什么、核验后系统发生了什么变化”。

本系统不做 ESG 评分、公司排名或投资建议。它优化的是有限人工复核资源的分配，并保持每项判断都能回到 PDF 原文证据。

## 2. Model Contract

### 2.1 子问题与模型映射

| 子问题 | 采用模型 | 不可替代的证据角色 | 备选方案 |
|---|---|---|---|
| 哪些抽取结果本身存在结构风险 | 可解释规则风险模型 | 识别单位缺失、比例误作次数、表头丢失等已知错误模式 | 纯 LLM 自评 |
| 哪些结果证据不稳定 | 证据不确定性模型 | 综合候选证据竞争、后处理修复、字段不完整及模型置信信息 | 只按置信度排序 |
| 哪些 missing 值得优先核验 | 同行披露缺口模型 | 用同一指标在全部报告中的披露普遍度区分“常见缺口”和“行业本就少见” | 固定指标清单 |
| 人工纠错如何影响后续任务 | Beta-Bernoulli 反馈风险模型 | 在小样本下平滑估计指标错误概率，同时保留未充分复核指标的探索价值 | 原始错误率 |

四类模型分别承担“已知风险、证据风险、语料背景、人的经验”四种证据角色，删除任一类都会丢失一种独立信息，因此不是重复堆叠。

### 2.2 复核优先级

对报告 `r` 的指标 `i` 定义复核优先级：

```text
Priority(r,i) = 100 × [0.35 R(r,i) + 0.25 U(r,i) + 0.25 G(r,i) + 0.15 F(i)]
```

- `R(r,i)`：规则风险。high / medium / low 分别映射为 1.0 / 0.7 / 0.4；无具体风险时为 0。
- `U(r,i)`：证据不确定性。由候选证据数量、模型置信信息是否可用、后处理修复和定量字段完整性组成，截断到 `[0,1]`。
- `G(r,i)`：同行披露缺口。仅对 missing 生效，取指标在全体语料中的 found 比例；低于 0.60 时不视为可行动缺口。
- `F(i)`：人工反馈风险。用 Beta(1,1) 先验平滑指标级错误概率，并与 `1/sqrt(n+1)` 的样本稀缺度组合，避免少量标注造成极端结论。

已完成复核的任务保留在图谱中，但默认降低优先级，使队列自然推进到下一项，而不是重复要求用户检查同一内容。

### 2.3 输出契约

每个优先任务必须输出：

- 报告、指标、状态和结构化结果；
- `priority_score` 及四个分量，禁止只给黑箱分数；
- 1—4 条可读的优先原因；
- PDF 页码、block_id、证据原文；
- missing 缺口对应的同指标同行证据示例；
- 当前人工复核状态。

## 3. 产品闭环

```text
上传报告
  → MinerU 结构化解析
  → ESG-65 证据约束抽取
  → 证据风险图生成复核队列
  → 一键跳转 PDF 证据
  → 人工修正 value / unit / evidence
  → 指标反馈风险更新
  → 队列重新排序
```

其中“证据风险图”由报告节点、指标节点、证据块节点、同行参照边和人工反馈边构成。第一版以可解释的结构化 API 实现图计算，不引入难以验证的图神经网络。

## 4. 与常见方案的差异

| 方案 | 能抽取 | 能回原文 | 能说明先审什么 | 能利用同行语料 | 人工反馈改变后续决策 |
|---|---:|---:|---:|---:|---:|
| Excel + 人工检索 | 否 | 人工 | 否 | 否 | 否 |
| 通用 PDF 问答 / RAG | 是 | 部分 | 否 | 否 | 通常否 |
| 原 ESG Evidence 仪表盘 | 是 | 是 | 否 | 否 | 只统计指标 |
| 可信披露诊断台 | 是 | 是 | 是 | 是 | 是 |

创新不在于单独发明新的基础模型，而在于把长文档解析、证据约束抽取、语料统计和人机协同组织成可解释、可闭环验证的审阅决策系统。

## 5. 评价指标

### 5.1 Inference 指标

- PDF 解析耗时、Qwen3 实际调用数与错误数；
- 单报告 65 指标处理耗时；
- evidence_quote 完整率、block_id 可解析率；
- 任务执行成功率。

### 5.2 诊断模型指标

- Top-K 风险覆盖率：前 K 个任务覆盖自动规则风险样本的比例；
- Workload Reduction：达到目标风险覆盖率时，相对全量 65 项需要核验的任务削减比例；
- Actionable Gap Count：同行 found 率不低于 0.60 的 missing 数量；
- Explanation Completeness：队列任务具有分量、原因、证据位置的比例；
- Feedback Responsiveness：保存人工标签前后，相同指标反馈分量和队列顺序是否按合同变化。

自动规则风险不是人工金标准，相关覆盖指标只能评价任务调度是否命中已知风险模式，不能冒充准确率。准确率、召回率和 F1 只基于人工复核数据计算。

## 7. 风险与边界

- 200 份报告不是严格行业分组，第一版称“语料同行基线”，不得宣称真实行业排名。
- 当前人工复核样本可能很少，反馈模型必须显示样本数和先验平滑，不宣称完成模型训练。
- found 率不等于披露质量；missing 缺口只提示“值得检查”，不判定违规。
- 自动规则风险是审阅提示，不是事实错误结论。
