## 4. 视频审查

项目视频已完成局部重制，不需要整片推倒重做。原审查发现的两处版本漂移均已解决：工作台口播不再提及已删除的“金标准管理”；工程验收画面与口播均已更新为当前仓库实测的 63 项 Python 测试和 16 项生产 smoke。

本次采用画面与配音分离的制作链：Remotion 重新渲染当前画面源码，36 个短句使用云扬男声独立合成并逐句设置语速、音调和不等长停顿，再由 FFmpeg 合成为最终 MP4。九个场景的口播均在各自画面边界内结束。

最终参数：

- 画面：1920×1080、30 fps、总时长不超过 300 秒；
- 工程：Remotion，短标题属于画面信息，不增加逐句字幕；
- 演示录屏：1920×1080，无个人浏览器信息，使用当前 `formal_current` 冻结数据；
- 配音：`zh-CN-YunyangNeural` 男声，按短句设置 -6% 至 +4% 语速、-2 Hz 至 0 Hz 音高；
- 配音母带：48 kHz、单声道、PCM，目标响度 -16 LUFS、True Peak -1.5 dB；
- 合成：FFmpeg，H.264 1080p + AAC，保持无字幕流；
- 音画复验：275.2 秒、1920×1080、30 fps、H.264/AAC、48 kHz 单声道、无字幕流，整片解码通过。
