# 管理措施

中电港将可持续发展理念深度融入供应链管理，着力确保供应链安全与稳定，加强供应商准入管理、分类管理及评价管理，常态化开展供应商沟通与交流活动，加速新产品、新技术的市场化推广和产业化应用，提升电子元器件产品供应连续、质量可靠，不断增强供应链的长期发展韧性。

# 供应商风险管理

中电港建立覆盖供应商全生命周期的风险管理体系，加强供应商准入审核及基础调查，通过跨部门协同对供应商的经营、履约、质量、服务以及可持续发展等维度开展年度综合评价，基于评估结果实施分级管理，以体系化手段筑牢供应链安全底线。

# 供应商准入管理

公司建立了系统化、规范化、协同化的供应商准入与调查机制。公司产品部门牵头组织通过座谈沟通、数据资料分析、现场调查以及企查查、国家企业信用信息公示系统等第三方风险排查系统，对供应商开展准入调查及评价工作，在掌握供应商基础资质能力的同时，了解供应商在质量管理、商业道德、劳工权益、安全生产、环境保护等 ESG 方面的表现，审核通过后方可纳入合格供应商名单。

# 供应商分类管理

公司针对供应商采取差异化的管理策略，提升采购决策效率。在将供应商依据业务类型分为分销类、封测加工类、自研产品类、技术服务类的同时，建立供应商“黑、白、灰”名单机制，对供应商进一步分类，鼓励与“白名单”供应商合作、严控与“灰名单”供应商合作、严禁与“黑名单”供应商合作。

# 供应商 评价管理

公司建立年度供应商综合评价机制，由业务管理部统筹，联合产品部门、运营中心及财务中心，围绕质量、价格、交期、服务及对账时效以及可持续发展现状等核心维度对供应商进行系统评估，依据评价结果将供应商划分为“优秀、优良、合格、不合格”四个等级，并对应实施差异化的合作策略，优先与优秀供应商深化合作，与优良供应商保持稳定关系，协同合格供应商进行改善，对不合格供应商采取限期整改或停止交易的措施，实现对供应商的动态、闭环管理。

# 供应商 沟通交流

公司注重与供应商建立透明、稳定的合作关系，通过协议、邮件及会议等方式保持日常沟通，持续推动技术交流、质量提升、交付保障与合规管理以及公司和下游客户对劳工人权、环境保护、廉洁反腐等方面的管理要求。我们不定期组织技术沙龙与专题座谈，分享市场动态与趋势，促进供应链协同发展。作为中国信息产业商会电子元器件应用与供应链分会理事长单位，公司积极依托协会平台，促进产业链上下游的互动与共享，共同构建可持续发展的产业生态。

# - 关键物质管理

基于中电港的核心业务特点，我们并不直接采购原材料，也不直接生产产品，但作为链接产业链上下游的枢纽企业，我们高度重视供应链产品中的冲突矿产以及有害物质使用情况，将“源头合规”作为供应链尽责管理的重要原则，一方面在原厂供应商选择过程中，我们优先与国内外知名原厂进行合作，依托其完善的合规流程实现风险隔离；另一方面，及时向上游原厂供应商传递客户合规要求，协同下游客户共同加强对上游供应商的管理。

# 冲突 矿产

倡导上下游企业共同遵循《联合国工商企业与人权指导原则》（UNGPs）、OECD《关于来自受冲突影响和高风险区域的矿产的负责任供应链尽职调查指南》以及《负责任矿产倡议》（RMI）等各项国际公认标准、倡议，在优先与国内外知名品牌合作实现风险规避的同时，积极响应下游客户的高标准合规诉求，根据客户对冲突矿产管理政策和尽职调查要求，推动原厂供应商反馈提供冲突矿产报告模板（CMRT）、扩展矿物报告模板（EMRT）等相关证明文件，并将相关要求及客户培训信息及时反馈共享到上游原厂。

# 有害物质

坚持从源头减少有害物质的使用，降低环境安全风险，根据《电器电子产品有害物质限制使用管理办法》《电子电气产品中限用物质的限量要求》以及欧盟《关于限制在电子电器设备中使用某些有害成分的指令》（RoHS 指令）等标准、政策规定，要求供应商加强原材料采购和生产过程管控，开展第三方限制有害物质检测与认证，并将认证结果作为分销类、加工类供应商准入的前提条件，推动电子行业向更环保的生产方式转型，促进绿色技术的应用。

我们积极倡导并践行绿色办公方式，从办公地址选择、办公方式优化、办公运营管理等方面入手，持续细化管理细节，推动全体员工养成绿色节约意识，减少办公过程中的环境影响。2025年，公司塘朗城及前海经贸中心办公区域用电费用同比降低6.46%。

# 办公地址选择

制定《办公区租赁管理细则》优先选择租赁公共交通便利、绿色物业服务管理完善、市政配套设施完善的公共楼宇，合理确定办公面积，为员工绿色出行，减少办公过程环境影响奠定基础。

# 办公方式优化

制定《行政服务指引》，大力推行线上化办公，线上传阅文件，使用电子印章。优化会议组织流程，明确空调使用要求和温度设置，加强打印用纸管理，提倡员工自带水杯、节约用水。

# 办公运营管理

加强环境保护监测，行政中心每周不定期监督巡视空调、灯具、水具使用情况，全面采用节能电灯、节水用具，并及时提醒关闭电源设备，及时维修受损设备，避免资源浪费。制定下发《大扫除执行要求》，每月组织办公区域大扫除，维护良好办公环境。

# 加强培训宣导

我们常态化开展环境保护宣传教育活动，大力倡导员工通过公共交通、骑行等方式出行，将绿色办公理念融入行政培训过程当中，推动绿色发展理念融入员工的日常行为当中。2025年，绿色办公员工培训宣贯覆盖率100%，亿安仓向全员宣导ESG及推行8S管理，落实资源节约要求。

# 污废水管理
