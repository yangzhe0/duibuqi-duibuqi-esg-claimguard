# 关于金种子酒

# 公司简介

安徽金种子酒业股份有限公司位于中国两大黄金名酒带之一的黄淮名酒带核心产区，传承自明代大升酒坊，正式建厂于1949年7月，是新中国首批酿酒企业，于1998年上市，是全国第八家白酒上市公司。公司现有“金种子”“种子”“醉三秋”“和泰”“颍州”五大白酒品牌，拥有2个“中国驰名商标”、1个“中华老字号”，是全国绿色食品示范企业。2023年金种子酒业以188.98亿元的品牌价值位列全国酒类榜单第67位。2005年，金种子酒业开创柔和品类，打造柔和种子酒成为单瓶销量破亿的行业大单品；2020年，与江南大学合作研发战略产品金种子馥合香，先后取得中国食品工业协会、中国酒业协会两大团体标准，是馥合香型白酒标准的定义者；2022年，华润入驻金种子集团，深入实施组织重塑和品牌重塑，为公司高质量发展注入了新的动能，全力做强主业白酒。金种子酒业以“引领白酒新世界、酿造美好新生活”为企业使命，不断守正创新，高标准打造绿色智能工厂、生态酿造科研基地、建立江南大学陈坚院士工作站、组建中国馥香白酒研究院等11个科研平台，先后荣获“国家地理标志保护产品”“全国绿色食品示范企业”，争做让消费者信赖、客户信任、员工自豪、投资者满意的中国一流白酒企业。

# 产品文化

# 金种子 馥合香系列

金种子馥合香是华润入驻金种子后重塑升级的核心战略产品，定位全国第13种香型的次高端白酒，该产品由非遗酿造团队精选六种粮食为酿酒原料，首创三曲融合配方，一步成香，一口三香。自2020年上市4年来，金种子馥合香以“芝头浓韵酱尾，一口三香”的独特品质享誉次高端、引领新名酒。金种子酒业先后取得中国食品工业协会、中国酒业协会两大团体标准，是馥合香型白酒的创领者。

阜阳特产“醉三秋”白酒历史悠久，源自刘伶“一醉三秋”的民间传说。相传魏晋时杜康后裔在汝阴（今阜阳）酿酒，刘伶闻香而至，醉卧三年，留下“杜康酿酒刘伶醉”的典故。宋代欧阳修、苏轼先后任颍州太守时，都喜饮颍酒并畅游西湖。凭借地理优势和文化底蕴，醉三秋发展为徽派浓香白酒标杆，品质密码为“五老”，即老技艺、老窖池、老陶坛、老酒、老匠心。其坚守老五甑浓香非遗工艺、坚定180天超长发酵、坚持5-20年真实年份老酒，延续了传统酿造技艺，彰显出“非遗”的独特价值，承载着阜阳人的老记忆、老情怀，是阜阳人印象里的老味道。

# 醉三秋系列

# 种子酒系列

“种子”象征生命、希望、传承与自强不息。金种子酒是国家地理标志保护产品。其起源可追溯至杜康秫酒，“秫”即种子。东汉《说文解字》记载杜康用种子酿酒，民间传说杜康因霉粮酿成酒浆。颍州地处中原，水源丰富，拥有百亿粮仓，为酿酒提供优质原料。种子酒传承宋代“颍州大曲”，延续传统“老五甑”工艺，是宋代颍州大曲的再现，兼具历史传承与现代柔和品质。金种子酒业于2005年首创柔和型白酒品类命名“种子酒柔和”并成功上市，至今连续畅销二十年，是柔和型白酒定义者，爱柔和，就喝种子酒。

# 金种子酒文化博物馆

金种子酒文化博物馆是一座集历史、文化与科技体验于一体的综合性展馆，总面积 3000 多平方米，分为四层，是展示金种子酒文化、传承酿酒技艺的重要窗口，重点发掘和展示与阜阳息息相关的酒文化传奇、人文历史及酿酒技艺，彰显阜阳作为中华酒文化重要发祥地的深厚底蕴。

博物馆一层为接待大厅及金种子工厂旗舰店；二层以酒道文化为核心，还原颍州民俗酒文化，设置酒令互动、调酒品鉴等体验区；三层聚焦酿酒工艺，展现金种子“老五甑”非遗技艺与馥合香创新工艺，介绍优质原料与深层矿岩水对酒质的保障；四层梳理企业从明代大昇酒坊至今的发展脉络，展现金种子品牌变迁与白酒香型文化。

馆内设有明代酒坊复原、西湖酒肆等沉浸式场景及各类互动装置，生动诠释“从一粒粮到一滴酒”的匠心精神，同时联动馆后明代古窖池，完整呈现金种子酿酒文化的传承与发展，让游客全方位感受白酒文化的博大精深与金种子的匠心传承。

# 明代古窖池

金种子明代窖池共 7 口，起源于明代中期，历史底蕴深厚，于 2013 年被省政府列入省级重点文物保护单位，在行业内享有 “中原第一窖” 之美誉。公司现存的 8000 余条窖池皆衍生于此，源于明窖的有益微生物菌群已被推广应用到公司所有酿酒窖池，保证新窖也能酿造出高品质白酒。

窖池及窖泥中滋生着种类丰富、功能多样且对酿酒有益的微生物菌落群。这些肉眼不可见的微生物能够利用谷物中的淀粉、蛋白质等营养成分，通过发酵作用生成浓香型白酒中各类呈香呈味物质。窖龄越长，窖池及窖泥中的微生物种类和数量就越丰富，生成的香味物质也就越多，白酒的香气便愈发醇厚浓郁。优质的窖池与窖泥，是生产高品质浓香型白酒的重要前提和核心基础。

# 发展历程

# 1949年7月—1950年7月

# 创立于龙王堂集的新中国首批国营酒厂——国营阜阳县酒厂

\- 1949年7月（阜阳于1948年8月解放），阜阳县税务局接管蕴泰酒坊，并将大升酒坊等数家私人酒坊并入蕴泰酒坊，并从阜阳、阜南、颍上、蒙城、临泉等地抽调人员成立国营阜阳县酒厂。新生的阜阳县酒厂与阜阳百年老字号“大升酒坊”、霍蕴年创办的蕴泰酒坊一脉相承。

# 1993 年—1998 年

# 创业创牌时期（1993—1998年）

\- 推出的新品牌“金种子”“种子”白酒家喻户晓，企业产值、销售、利税连年翻番，厂长锁炳勋于1995年元旦，将阜阳酿酒总厂更名为“安徽种子酒总厂”，1996年11月以种子酒总厂为核心企业成立“安徽金种子集团有限公司”。

# 2004—2009年

# 产业整合时期

\- 2006年9月5日起，安徽金牛实业股份有限公司正式更名为“安徽金种子酒业股份有限公司”。2005年5月，首创柔和型白酒和物理恒温窖藏新技术，成功推出柔和种子酒、祥和种子酒、恒温窖藏地蕴醉三秋三款产品，柔和种子酒连续畅销十余年，成为单品销量过亿瓶的超级大单品，创行业奇迹。

# 2019年10月—2022年

# 推进高质量发展新时期

\- 2019年10月，贾光明出任安徽金种子集团董事长，兼任安徽金种子酒业董事长，先后引进北京和君咨询、安永（中国）咨询、盛初咨询，制定了“十四五”发展战略，改革创新成效显著，金种子驶入高质量发展新轨道。

# 1950年8月—1992年

# 走出安徽——代表安徽酒企参加评酒会

- 1952 年，阜阳县酒厂代表安徽酒企参加第一届全国白酒评酒会。  
- 1981年、1983年、1986年，醉三秋酒连续三届获评安徽名酒，1990年获评轻工业部部优产品。  
- 1992 年 7 月，阜阳县酒厂兼并阜阳插花镇的颍泉酒厂，更名为“阜阳酿酒总厂”。

# 2010－2019年

# 转型升级阶段

\- 高起点建成金种子生态酿造科研基地一期工程、白酒灌装中心、酒体设计中心、品控研发大楼，企业生产规模和生产能力实现跃升。在科技创新上，组建了CNAS国家认可实验室、博士后工作站、大师工作室等11个科研平台，成功推进“浓、酱、芝”三香融合的馥合香型白酒研发。在营销上大力发展电商、定制酒业务，“金种子”“醉三秋”分别获评中国驰名商标，颍州佳酿酒被商务部评定为“中华老字号”产品。

# 影响、风险与机遇管理

公司高度重视信息安全管理工作，制定《信息系统用户账户及权限管理说明》，明确涵盖账户分类、权限管理、密码策略、应急响应和定期审计等核心内容，从制度层面防范数据泄露风险。同时，通过明确各部门职责分工，聚焦离职账号清理、权限与岗位匹配、账号共用等核心风险点，制定数据导出、在线复核、权限整改分阶段工作计划，进一步规范权限管理流程，清理冗余账户、优化权限匹配，有效降低账户权限类安全风险，保障业务系统稳定运行。

公司强化办公设备与人员管理，对本地办公设备业务台账实施动态管理，实时调整人员与办公设备的动态变更信息；每半年开展一次全公司自助盘点，实现人员与办公设备的精准对应、规范管理，从终端层面防范信息安全隐患。

公司完善硬件与系统支撑，新增 UPS 电源设备，在突发停电时可提供应急电力供应、稳定电压、净化电源及防浪涌保护，保障关键设备持续运行，守护设备运行过程中的数据安全；新增原酒管理系统云端服务集群，并采购防爆 PDA 设备，用于原酒业务日常管理与数据上传，规范业务数据采集、传输流程，进一步强化核心业务信息安全。

# 案例：新型脉冲布袋除尘器

# 固体废弃物管理

公司的固体废弃物主要分为一般废弃物和危险废弃物，实行分类管控、分级处置。对于一般废弃物，在厂区内设置规范分类设施，经分类整理后进行合规处置，对于危险废弃物，则委托给有资质的单位处置，设立规范的危废暂存间管理体制，加强危废收运管理，确保危险废弃物转移过程中无洒落、无泄漏，杜绝二次污染。

公司强化源头削减、资源回收利用和末端安全处置的原则，致力于实现废弃物的减量化、资源化和无害化。公司积极推进废弃物资源化再利用，最大化挖掘废弃物价值，将污泥用于制砖原料使用、酒糟优先在酿造环节用于配醅使用，剩余酒糟对外出售，用于养牛等领域。

针对危险废弃物，公司重点强化源头管控与全流程监管，减少其产生量和危害性。公司加强源头控制，采用清洁技术和低污染工艺，改进检测方法，减少有机试剂使用量，采用先进工艺技术与设备，降低危废产生；将酒醅监测方法由化学检测改为近红外光谱仪仪器检测，减少废液产生，同时推广使用清洁能源与原料，从根源上减少危险废弃物产生。

# 供应链管理

# 治理

公司持续完善供应链管理体系，设立由总经理及各业务分管领导组成的采购委员会，作为采购管理的最高决策机构，决定公司采购战略规划及管控模式，由采购专业委员会审批把控采购方案和考核结果等，并由采购供应部负责采购管理和供应商管理。

# 供应商管理流程

公司供应商目录实行引进、评价、淘汰动态循环机制，供应商管理一般按照开发、认证、考核、分类四个程序开展：

# 开发

采购主责部门根据业务需求分品类制定资质或现场认证标准并公开，通过守正平台、市场走访等多种渠道公开寻源，收集潜在供应商资源信息并整理登记

![](images/eb2025ea11f5b785a731fc2a8e2943cae50125d22efe943139525c3ac4e03c49.jpg)

# 认证

依据品类特点确定认证范围，新供应商认证分资质和现场认证，资质认证审核相关证件，现场认证按标准组建小组开展，不合格可整改，合作供应商认证周期不超过3年

# 分类

采购主责部门将供应商按业务需求分类，包括品类供应商、黑名单供应商等，分别依据相应条件建立目录并管理，同时对包材供应商开展星级管理，通过多种方式帮助供应商提升能力

# 考核

采购主责部门建立考核评价标准，明确考核项目、标准、周期及数据来源，及时处理合作过程中的问题，年度考核评价后按结果进行管理

# 供应商考核结果应用

供应商考核分为过程考核和年度评价，过程考核通过对供应商合作过程中出现的交付、质量、违规等问题进行考核，如发现重大问题，可能采取警示、约谈、货源扣减、暂停供货甚至直接淘汰的措施。年度评价则通过对合格供应商现场考察认证、合作考核、质量延伸等进行全过程的年度评价，年度综合评价报告将上报给采购委员会，也是作为供应商星级管理依据之一，如年度评价不合格将予以淘汰。

# 供应商赋能

公司始终重视供应商协同合作，组织交流会、对标及专项培训，全面宣导供应商管理制度与质量标准要求。公司积极推进质量延伸管理机制，通过现场认证查找问题、提出改进建议，通过专题会议推广行业新技术、新设备、新方法应用等，帮助供应商进行问题攻关、技能提升，以满足公司发展需要。

# 阳光采购

公司加强供应商管理工作廉政建设，推进反腐倡廉向纵深开展，制定并严格遵守供应商制度中的廉洁管理规定，若供应商管理人员与关键岗位等存在利益关系应主动申报；所有物资类除应急生产及应急安全类物资，均通过华润守正采购交易平台公开采购；大宗物资采购通过华润守正采购交易平台发布包装物、原料类大宗物资供应商征集公告。

公司明确廉洁合作条款，将廉洁合规承诺书作为合同附件要求供应商进行签署，签署率达100%。若发现任何供应商黑名单行为，将供应商认定为黑名单供应商，至少5年内禁止合作。

# 供应商紧急事件管理

供应商如出现信用危机、食品安全、生产经营场所发生重大事故 / 事件等情形时，公司获知后将第一时间形成紧急事件报告，调查并持续跟踪事件情况和发展趋向，并提出应对措施落实，直至紧急事件对公司的影响消除。

# 绿色采购

公司增加绿色原料采购标准要求，针对小麦、高粱等六类核心原料制定包含绿色食品认证的考察认证标准，并要求有资质的供应商提供绿色食品认证证书，逐步扩大绿色原料的使用比例。公司还长期开展包装优化项目，报告期内通过调整印刷方式、材质，使用无纺布袋等方式，进一步推动包装材料执行减量、轻量化设计。

# 践行乡村振兴

公司坚守国企担当，将助力乡村振兴作为履行社会责任的重要抓手，聚焦临泉县长官镇王营村定点帮扶工作，以党建为引领、产业为核心、民生为根本、治理为支撑，全方位推动乡村发展、乡村建设、乡村治理，扎实谱写乡村振兴新篇章。

![](images/fb1f676b7efa34afbd7131c51d8bb75491ed987496495ddb24c27b5a18022caa.jpg)

# 筑牢红色堡垒

- 公司派驻专业驻村工作队，深耕王营村基层党建，全年组织6次党员大会，开展党的创新理论与惠农政策学习，推行“流动书包”送学上门，确保党的政策方针直达基层、深入人心；  
- 创新“退伍军人 + 党员”双带头机制，充分发挥党员先锋模范作用，凝聚乡村发展合力；  
- 推行“有事找书记工作法”，建立党员联户包片机制，全年化解矛盾纠纷47起，显著提升党组织凝聚力与号召力。

![](images/7eb87fa5ad787c17fd2be3d8a2c1f61ea8d16be66b684285150f05b935ffd589.jpg)

# 激活产业引擎

- 构建“党支部 + 合作社 + 农户”模式，带动120户脱贫户通过土地流转、入股分红、务工就业增收；  
- 推动特色种植、水产养殖成为村集体经济新增长点，有效盘活闲置资源，实现“单一田”向“聚宝盆”转变；  
- 建立“企业 + 村集体 + 农户”产销对接机制，做活帮扶联动，全年帮助村民销售特色产品6.1万余元；  
- 引入长官镇花篮编织厂，开设“乡村车间”，培训50名留守妇女掌握编织技艺，人均月增收800元；  
- 瞄准“农旅融合”潜力，开发“田园观光 + 农事体验”微旅游线路，做强三产融合，丰富乡村产业形态；  
- 协调上级有关部门开展为期四天的“巾帼创业就业电商直播培训班”，提升农村女性电商技能，拓宽创业增收渠道，助力女性实现自主创业。

![](images/46e60649d3f9c52b3ef32d9b04b107fb6e51c867e1c12a9e60c408d61f99c1ac.jpg)

![](images/7cbe27c2a6d5cda33ca3edc5013125c6c2befc4230a165aa5e449a3d79532f47.jpg)

# 创新治理模式

- 推行“积分制 + 清单制”，依托捐赠的 1.4 万元物资，建立“积分超市”，村民参与环境整治、志愿服务可兑换生活用品，调动村民参与乡村建设的积极性；  
- 邀请镇司法所开展“法律讲堂”，增设“法治文化墙”“反诈宣传角”，针对留守老人易受骗问题，组织村“两委”干部党员志愿者深入自然村开展村头群众会，宣传防“电信诈骗”知识；  
- 协同王营村委会开展 2025 年度 “最美媳妇” “最美婆婆” “最美村嫂” 评选活动，树立文明榜样；  
- 开展 “纪念三八国际妇女节” “纪念抗日战争胜利 80 周年优秀退伍军人表扬” 等活动，对先进典型给予奖励，将其事迹搬上文化墙，引导村民践行 “孝老爱亲、邻里互助” 的良好风尚；  
- 开展“情暖重阳，银龄关爱”主题活动，采用“集中服务 + 上门慰问”双模式，关爱村内老年群体，传承尊老敬老传统美德；  
- 组建“志愿宣讲团”，8名“最美村嫂”、5名老党员义务宣讲政策、调解纠纷，推动乡村治理提质增效。

![](images/d63f5ff6e5c6d93b18a830401817e5b9129407a5edca666b8dd947dfdfaccf76.jpg)

# 办好民生实事

- 集团聚焦民生福祉，用心办好惠民实事。协调资金硬化自然村巷道25条，推进主干道加宽修缮，全村道路硬化率达 $98\%$ ，解决群众出行难题；  
- 完善农家书屋、建成幸福院，健全文化与养老阵地；  
- 开展 5 次防返贫大走访，为监测户制定 “一户一策”，落实医疗、教育帮扶，为老人建立健康档案，办理低保、困难救助，筑牢防返贫底线；  
- 重点关注留守儿童、孤寡老人等群体，累计出资万余元，在重要节日送去生活物资与学习用品。
