# 走进天禾股份

# 公司简介

广东天禾农资股份有限公司于2009年3月通过股份制改组设立，是广东省供销合作联社的直属企业之一，前身是成立于1952年的广东省农业生产资料总公司，有着70余年的经营历史。公司于2020年9月在深圳证券交易所挂牌上市。公司以现代农技服务为先导、直达终端的配送体系为支撑，主要从事化肥、农药等农资产品的销售并提供专业的农技服务、农业社会化服务。2025年，公司获评全国农资流通企业综合竞争力AAAAA级，是中国具有较大品牌影响力的农资流通服务企业，是广东省重点农业龙头企业和农业产业化国家重点龙头企业。

在广东省供销合作联社深入推进“四网一基地一平台”公共型农业社会化服务体系建设的总体布局下，公司立足生产服务端，持续深化“以农户为中心，以作物为导向”理念，做强“农资流通基本盘、农业社会化服务体系”两大通道，促进营养、植保、农服“三网”融合发展，协同推动广东粮食和特色优势农产品全产业链价值提升，致力于发展成为国内现代农业生产综合服务的引领者。

公司持续巩固农资流通主渠道地位。近年来，公司年均向全国市场供应各类化肥超400万吨、供应农药超25亿元，全力保障农业生产需求。截至报告期末，公司已在全国22个主要农业生产省区和农资集散地建立了102家配送中心，直接对接服务的终端核心门店和种植大户超2,5000家，服务区域实现24小时全天候响应，2小时内产品送达。

公司充分发挥农业社会化服务主力军作用。公司自2021年起牵头推进“4+100+1000”农资农技服务网络建设，目前已在广东省建设了4个区域服务中心、51家县域中心、516家镇村作物服务中心，服务覆盖全省所有水稻主产区。2021年至今，公司在广东省开展农业社会化服务近2,000万亩，其中2025年服务面积实现802万亩，同比增长45%，并实现了良好的经济、社会和生态效益。

公司紧紧围绕服务广东省供销合作联社综合改革大局，全面推进战略转型，在广东因地制宜发展合作经济，协同“四网一基地一平台”、各级供销社、村集体、广大农户大力开展“社村”合作试点，深化“订单农业+全程社会化服务”模式，协同打通丝苗米、甘薯、甜玉米、豇豆等广东粮食和重要农产品全产业链，致力推动农产品全产业链价值提升，促进产业增值增效、农户增产增收、村集体经济发展壮大。

# 发展战略

天禾股份认真落实广东省委“1310”具体部署、实施“百千万工程”，聚焦服务广东省供销社综合改革和“四网一基地一平台”建设，深化“以农户为中心、以作物为导向”理念，围绕“发展成为全国领先的现代农业生产综合服务龙头企业愿景，做大农资流通基本盘、做强农资农技服务网络，实现三网融合发展”的“1个愿景、2大通道、3网融合发展”战略，打造广东粮食和重要农产品产地供应链，以现代农业生产综合服务带动公司传统农资经营模式高质量转型升级，促进产业增值增效、农户增产增收、新型农村集体经济发展壮大。

公司严格遵守《中华人民共和国反不正当竞争法》等相关法律法规，公平参与市场竞争，坚决杜绝虚假宣传、垄断行为、侵犯商业秘密等任何形式的不正当竞争，并将合规要求全面融入采购、生产、销售等各业务环节。内部管理上，公司明确规范员工行为，严禁从事或协助与公司存在竞争关系的业务，不得为竞争对手提供便利，致力于维护公平、健康的市场环境，推动行业可持续高质量发展。

# 数据安全管理

公司通过完善专项制度与明确管理职责,系统化构建数据安全管理体系。公司制定并施行《办公计算机设备租赁管理办法》及《办公计算机设备桌面安全管理办法》《数据中心机房管理办法》等制度,对计算机设备从采购、使用到报废的全周期,以及数据中心机房的物理环境、人员访问与数据操作进行系统化规范。公司明确由信息技术部作为数据安全管理的归口责任部门,主要负责数字化建设、系统与机房运维、设备资产的全周期管理、网络与数据安全及人才培养等工作,并下设应用项目组、应用运维组、开发组、基础架构组,分工承接数据安全相关管理与执行职责,构建层级清晰、责任到岗的管理体系。

# 应急救灾

# ·应对台风灾害,保障农业生产与灾后恢复

为应对台风“蝴蝶”带来的不利影响,天禾股份迅速行动,聚焦重点区域与产业,统筹资源,协同推进防灾减灾与复产保供工作,全力保障农业生产安全。

在茂名荔枝主产区，公司着力强化全链条生产保障。通过组织超600场全省荔枝植保农技服务活动，为超19,000名农户提供技术培训，增强防灾能力。为降低采收损失，公司在9个主产区组建了单日采收能力达300吨的2,000人专业服务队，累计协助2,813户果农抢收荔枝约2,096吨。同时，联合相关部门引入智能检测设备，建立农残全流程管理体系，并对人员开展专项培训，严格把控果品质量。台风过境前后，高州、廉江公司积极协助农户开展预警巡查、雨后排涝及杀菌防病、营养复壮等技术指导，针对性防控晚熟品种落果、裂果及病害。

在肇庆怀集洪涝灾区, 公司全力驰援应急抢险与灾后重建。公司快速响应当地政府号召, 紧急从周边分公司调集力量, 组建23人抢险突击队深入重灾区, 完成了50余户居民点和临街商铺的清淤与垃圾转运工作。公司及时向受灾群众发放矿泉水、方便面等应急生活物资超250套(箱), 保障基本生活需求。灾情稳定后, 有序组织受灾农户进行技术培训, 发放“复产套装”并跟进补药施肥等社会化服务, 助力当地尽快恢复农业生产秩序。

在台山粮区, 公司重点依托科技赋能实现精准管护。台风后, 立即联动相关部门及基层服务网络, 组织农技人员开展拉网式巡田, 预防病虫害大面积爆发, 并对破口抽穗期水稻全面实施“一喷多促”作业。公司强化智慧农业应用, 通过部署在都斛、斗山等镇的物联网站点动态监测田间数据, 并组织无人机进行靶向施药。此项精准作业模式在减少用药次数与用量的同时, 有效保障了夏粮的稳产增效。

# 治理

天禾股份“诚信为本，服务‘三农’”的经营宗旨，制定《农资商品准入制度》，确保公司所有农资经营活动和经营的所有农资商品必须符合国家有关法律和法规的规定，切实从采购源头上把好农资商品质量关。

公司已构建标准化评价与动态管理流程。首先，公司对所有合作的供应商实行资质审查，以确保供应商的资质符合国家法律和法规所规定的基本条件，而且必须符合双方合作具体产品(品种)所必需的特定资质条件。其次，公司按照规定建立了供应商评价体系，涵盖信用评价、准入审批等内容，全面审查供应商资质，确保其符合国家法律及产品特定要求。

为实现流程的高效与客观,公司借助信息系统与第三方大数据平台,统一评估供应商信誉并共享信息,经评估合格后列入“供应商数据库”。

# 物流管理

公司突破了农资流通行业“重流通、轻服务”的多级分销传统模式，通过深化“配送网络终端化”战略，构建了完善的农资终端配送服务网络体系。公司在全国22个省份及北京市建立了102家配送中心，均位于交通便利的铁路、陆路、水运中转枢纽，所有区域配送中心均配备专业配送车辆、专业农资农技服务人员，已在服务区域实现了24小时全天候响应，2小时内产品送达，打通农资配送与农户之间的“最后一公里”。

# 产品质量监测与产品有害物质监测

公司重视产品质量安全，并建立完整的内部质量控制体系。例如，中加化肥制定了《产成品检验规程》《原材料检验规程》等一系列管理流程，珠海瑞农制定了《原材料入库检验》《中控管理制度》《出厂检验制度》等制度。这些制度共同构成了公司从原料入厂到产品出厂的全链条质量监测网络，为产品质量的稳定与可靠奠定了坚实的制度基础。

公司将有害物质管理作为质量监控的核心环节,通过建立有害物质安全评估机制,不断提升有害物质管理水平,保障产品健康与安全。例如,中加化肥对原材料进仓执行检验要求,保证从原材料开始控制有毒有害物质的含量,确保产品符合环保生态肥料要求;钾肥部针对老挝颗粒氯化钾等产品主动实施外部送检。这些措施共同形成了从评估、入料到出厂检验的严密管理链条,切实保障了产品的安全与环保品质。

# 绩效管理

天禾股份根据《员工绩效管理制度》，遵循“客观公正、民主公开，分类考核，定量指标与定性分析相结合”的原则，从员工工作业绩、能力表现与工作态度等方面开展综合评价，持续激发员工工作积极性，促进个人成长与组织绩效协同提升。

公司设立薪酬绩效考核领导小组，对绩效管理工作进行统筹指导与监督；人力资源部作为绩效管理的常设执行机构，负责组织实施相关工作，并结合不同岗位职责与工作要求，实施分层分类的考核安排，确保评价过程规范有序、结果公平合理。

# 安全生产管理体系

公司坚持“安全第一、预防为主、综合治理”方针，严格遵循《中华人民共和国安全生产法》《中华人民共和国职业病防治法》等法律法规要求，将员工生命安全与职业健康放在首位，持续完善安全管理体系与职业健康，努力为员工营造安全、可靠、健康的工作环境。

公司制定了《安全管理基本制度》《全员安全生产责任制》《安全管理分类分级实施办法》《生产安全事故应急管理和报告处理制度》等共计16项管理制度，对安全管理组织架构、岗位职责、运行机制、应急处置流程、安全培训与监督检查、消防管理等关键环节作出明确规定，实现对安全生产重点领域和核心流程的全面覆盖，为各级单位规范开展安全管理工作提供了坚实制度支撑。报告期内，公司新制定2项安全规章，修订6份规章制度和5项操作规程，并出台1项安全指引，进一步夯实安全生产管理基础。

公司实行“公司—部门—控股子公司”的三级安全管理体系，公司经营班子领导，安全生产管理机构监管，各单位各司其职、各负其责、一把手负总则、全员参与，安全生产工作按照“三管三必须”原则实行属地化管理。

# 安全生产风险管理

# ◎ 风险管理机制

公司制定并实施《安全生产风险分级管控制度》，坚持“全面辨识、科学评估、分级管控”的原则，着力构建“双重预防”机制体系，形成覆盖“风险辨识—风险评价和分级—风险控制”的闭环管理模式。

# 管理环节

# 主要内容

# 风险辨识

紧扣本单位生产经营实际,全面辨识生产工艺、设备设施、人员行为、农资储存、工作环境、业务流程和管理体系等方面存在的危险源。

# 风险评价和分级

采用作业条件危险性分析法(LEC法)对已辨识风险进行分析分级, 将安全风险划分为重大风险、较大风险、一般风险和低风险四个等级。

# 风险控制

按照风险等级实施差异化管控措施, 明确责任主体, 落实现场管控要求, 并纳入日常检查和隐患整改闭环管理。

# 隐患排查

为建立安全生产检查和事故隐患排查治理长效机制，公司制定并实施《安全生产检查和隐患排查治理规定》，建立安全生产“一线三排”工作机制，由主要负责人组织建立并落实安全风险分级管控和隐患排查治理双重预防工作机制，督促、检查本单位的安全生产工作，及时消除生产安全事故隐患。整改责任单位对发现的隐患和问题按照轻重缓急实施分类处置，及时采取措施予以整改消除。整改完成后，由督办负责人或组织检查单位开展复查验收，合格的予以核销；对整改不到位或逾期未改的，依据有关规定实施约谈、通报等问责措施，持续强化隐患治理成效。同时，公司引入第三方专业机构参与安全风险排查与评估。报告期内，公司整治391项隐患，整改完成率100%。

通过现代化生产设备升级和专业技术人才的配置,优化产品配方,减少农药使用量,降低对环境的影响。同时,推广高效低风险农药,提高农药利用率与安全性。

# 生产有机肥

通过动物粪便好氧堆肥等技术,对禽畜粪便进行无害化、资源化处理,生产优质有机肥,有效减少温室气体排放。同时,有机肥能够提升农田土壤有机质含量,还田固碳,间接减少上游化肥生产,实现碳减排。

# 南雄高标准农田建设项目

结合酸化耕地治理、撂荒整治及灌区建设,有效提升耕地质量等级,实现宜机化改造与耕作面积增加,改善了农业生态环境,打造了生态友好的示范工程。

# 农业面源污染防控项目

通过实施农作物病虫害统防统治、肥料统配统施、农作物营养解决方案、农作物植保解决方案等农业社会化服务，并开展农业技术培训、普及农业面源污染防治知识和实用技术等措施，持续推进化肥农药减量增效，形成可复制、可推广的农业面源污染防控格局。

# 紫云英绿肥项目

通过开展紫云英种植，包括种子处理、播种、施肥、开沟、排灌等田间管理等关键环节，有效固氮增肥、改良土壤结构，减少化肥施用并提升后茬作物产量，同时能利用冬闲田固土保水、美化田园，兼具生态效益与经济收益。

# - 环境隐患排查

为有效预防环境风险,珠海瑞农和大丰植保制定了《环境隐患排查治理责任制度》,明确了从总经理、副总经理、环保管理人员到班组长的分级职责体系。总经理为第一责任人,全面负责隐患排查治理;副总经理组织落实排查工作;环保管理人员具体推动并监督整改;班组长负责本班组的日常检查与上报。隐患排查工作遵循“谁排查、谁负责;谁签字、谁负责;谁主管、谁负责”的原则,实行责任到人。公司通过建立常态化检查机制,定期开展环保监督检查与环境风险排查,并在重大节假日前由领导带队组织环保大检查、环境风险排查。对发现的隐患实行记录跟踪、明确责任人与整改期限,确保整改落实,形成闭环管理。2025年9月,在台风受灾后,珠海瑞农对办公楼、仓库、水剂车间、厂区等重点区域开展全面环境隐患排查,共发现隐患问题7项,均已全部整改完毕。

生活污水则严格执行排放标准,经三级化粪池处理,达到广东省《水污染物排放限值》(DB44/26-2001)第二时段三级标准后,纳入市政污水管网,最终输送至珠海市南水水质净化厂进行深度处理,确保符合环保要求。

# 噪声管理

公司持续加强对生产运营中噪声排放的控制与监测。壹号生物依据《自行监测方案》每季度进行手工噪声监测。中加化肥严格执行《废弃物与其他污染物管理制度》，通过合理布局设备、落实隔音降噪措施，并对高噪声设备定期维护保养，确保厂界噪声达标。此外，壹号生物和中加化肥均委托具备资质的第三方进行厂界噪声检测，确保排放符合法规要求，落实环境管理责任。

# 废弃物处理

公司着力构建并运行覆盖废弃物全生命周期的规范处理流程,通过明确分类、专业处置与责任落实,持续推动环境影响的系统化管控与降低。

# 废弃物管理体系与制度

公司建立了完善的废弃物管理体系，各下属生产企业均制定了专项制度并严格执行。其中，中加化肥制定了《废弃物与其他污染物管理制度》，规范废弃物的分类收集、规范贮存，并委托有资质单位进行清运与处置。珠海瑞农、大丰植保等公司则制定了《厂区废弃物管理作业程序》《危险废物污染防治责任信息公开管理制度》《农药包装废弃物回收与处置管理制度》等制度，分别规范废弃物的分类收集与委外清理、危险废物的全过程控制，以及农药包装废弃物的专门回收与处置跟踪。

# 废弃物管理措施

公司及下属生产企业对废弃物实施严格的分类管理,通过推动一般废弃物的资源化利用与危险废物的专业管控,确保各类废弃物均得到合规、安全处置,以系统性管理减少对环境的影响,践行企业环境责任。
