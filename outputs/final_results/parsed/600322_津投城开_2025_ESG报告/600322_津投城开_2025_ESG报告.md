# 公司简介

天津津投城市开发股份有限公司（以下简称“津投城开”，股票代码“600322”）是天津市最早成立的房地产综合开发企业。公司拥有国家房地产开发一级资质，并于1992年实行股份制试点改革，于2001年在上海证券交易所成功上市，成为天津市房地产行业首家上市企业。

上市以来，公司不断发展，形成了以房地产开发经营为主，物业管理为辅，集商品房销售、商业资产运营和建筑材料经营为一体的业务格局。公司长期致力于城市开发与保障性住房建设，先后五次荣获“广厦奖”，四次获得“詹天佑金奖”。报告期内，公司在建及在售项目主要有东丽区沙柳北路A、B地块，河北区盛文佳苑，津南区林里公园，以及苏州美瑜华庭等。

# 1) 装配式建筑

公司积极响应国家关于发展装配式建筑、推动建筑业转型升级的政策要求，将装配式建筑作为提升建造效率、降低资源消耗和减少施工环境影响的重要抓手，推动建造方式向标准化、低碳化转型。

在装配式建筑实践中，公司通过主体结构与内装系统分离、构件工厂化生产和现场装配施工，有效减少施工现场湿作业比例，降低扬尘、噪声和建筑垃圾产生量，提高施工效率和工程质量，为推进绿色低碳建造提供有力支撑。

在土地资源集约利用方面，架空设计有效整合设备用房和配套功能空间，减少对地面绿化和公共活动空间的占用，在提升居住品质的同时，降低土地开发强度。

# 1) 扬尘治理

公司将施工扬尘防控作为文明施工和环境管理的重要内容，围绕土方作业、拆除作业、物料堆放与运输、场内道路通行等扬尘高发环节实施全过程管控。

施工现场按要求设置连续封闭围挡，重点区域道路硬化、定期清扫保洁，减少车辆碾压与二次扬尘。对裸露土方、临时堆土及易产生扬尘的散装物料实施全覆盖管理，采取防尘网、苫布等方式降低风蚀扬尘风险；在土方开挖、回填、装卸等作业过程中，配套洒水、喷雾、雾炮等降尘设施，结合气象条件实施定时、定点抑尘作业，提升扬尘控制的针对性与有效性。在非施工时段，通过视频监控系统对现场进行远程巡查，确保施工场地始终保持规范有序状态。通过一系列综合治理措施，公司在建项目施工扬尘得到有效控制，相关指标稳定符合国家和地方环境管理标准。

同时，公司强化运输环节管理，推动车辆规范冲洗、密闭运输与路线管控，减少“带泥上路、沿途遗撒”等问题。在不利气象条件或重污染天气期间，严格执行属地管控要求，及时调整作业计划、加密抑尘频次或采取停限措施，确保施工扬尘风险可控、现场管理标准不降。

# 2）噪声治理

公司高度重视施工噪声管控，严格执行建筑施工噪声污染防治和文明施工相关规定，将噪声防控纳入施工组织设计与现场管理全过程。

项目建设优先选用低噪声施工机械设备，并定期开展维护保养，减少因设备老化、部件松动等造成的异常噪声。对搅拌机、电锯等固定噪声源，结合现场条件设置隔音棚、隔声屏障或采取合理布置与封闭作业方式，降低噪声传播强度。

# 施工噪声管控

在施工时间安排上，公司严格落实属地噪声管控时段要求，尽量避开夜间及居民休息时段开展高噪声作业；确需连续作业或特殊作业的，依法依规履行审批手续，并做好提前告知与沟通协调，降低扰民风险。

公司同步畅通现场反馈与处置机制，对周边居民反映的问题及时核查、快速整改，推动噪声治理从“事后处理”向“前置预防”强化。

# 3）废水治理

公司坚持 “雨污分流、分类收集、规范处理、达标排放” 的原则，持续完善施工废水管理。各项目对施工废水、车辆冲洗废水、设备清洗废水等分类收集处理，经沉淀、过滤等措施达到相关要求后方可排入市政管网，严禁污水直排、跑冒滴漏。对雨季易发生径流污染的环节，公司加强临时排水系统维护与现场巡查，避免泥浆外溢和雨污混排。

# 4）固废与危废治理

公司坚持施工废弃物 “分类管理、规范处置、资源化优先” 的原则，在施工现场设置标识清晰的分类收集设施，对建筑垃圾、生活垃圾及危险废物实行分区管理、专人负责，确保收集、暂存、转运全过程可控。建筑垃圾做到及时清运，防止长期堆存造成扬尘、渗漏与环境脏乱；对具备回收利用条件的废弃物，如废砖、废混凝土等，结合项目实际推动破碎筛分后用于场地回填、临时道路铺设等，提高资源化利用水平。

报告期内，津投城开构建起以风险管理为核心、内部控制为支撑的治理保障体系，全面覆盖经营管理各环节。建立全流程风险管控机制，精准识别、评估、管控风险。通过健全内控规章制度、明确权责分工、强化流程监督，形成风险预警、处置与复盘的闭环管理。持续优化内控流程与风控技术，保障公司经营决策科学合规，有效防范化解各类风险，护航企业高质量发展。

# 风险管理体系

津投城开建立内审与外审协同发力的风险管理体系，为合规经营与稳健发展筑牢坚实保障。内审立足企业内部管理需求，围绕内部控制与全面风险管理开展工作，覆盖经营发展各领域各环节，重点抓实三项法律审核等法治基础工作，通过机制优化完善持续提升内部治理与风险防控水平。外审借助外部律师专业资源，与公司法务部形成工作合力，全方位参与公司法律风险防范相关工作，从合规体系建设、风险应对处置到专业能力培训多维度发力，有效补强公司风险防控专业支撑，构建起内外联动、全域覆盖的风险防控格局。

# 内审方面

内审主要关注企业的内部控制和风险管理，范围相对广泛，涵盖组织的各个方面，包括财务、运营、合规、风险管理等，特别是在规章制度、经济合同和重要决策法律审核（以下简称三项法律审核）等法治基础性工作上下大功夫，筑牢法治城开的体制之基，报告期内三项法律审核已优化完善，取得了显著效果。

# 外审方面

外审是指聘用外部律师，配合公司法务人员完成公司法律风险防范工作。包括负责进行日常合规问题的解答（如梳理存在的法律风险并出具整改建议）、合规体系的建设（如设计多业务板块的一体化合规组织架构、全面完善合规制度体系）、合规事件的应对（如配合公司接受合规行政调查，进行综合危机管控）和相关专题（如反垄断、反腐败、公司法、刑事等方面）的培训。

公司按照国家法律法规规定及上级主管单位要求，构建并完善“三道防线”责任体系，严格执行合规审查机制，所有重要规章制度、经济合同、重大决策必须经过法务合规部门审查，并留痕存档；建立合规咨询便捷渠道，法务人员、公司律师及时解答回复；对全员开展合规培训，通过常态化培训、高管宣讲、案例警示等方式，将合规要求嵌入企业文化与员工行为准则，使合规从外在要求内化为行为自觉。

# 业务部门

业务部门作为风险识别第一道防线，立足日常经营全业务流程，承担前端风险排查首要职责。通过建立常态化风险排查机制，将风险识别嵌入日常工作各环节，实时收集、初步研判各类潜在风险信息，及时向上传导风险信号，为后续风险管控提供基础支撑。

# 风控合规部门

风控合规部门作为风险管理的统筹管控主体，承接前端业务风险信息，搭建系统化、标准化的风险管理体系。牵头制定风险管理制度、管控标准及操作流程，明确各领域风险识别要点与处置规范，统筹跨部门风险研判与协同管控。通过常态化巡查、专项核查，监督业务部门风险责任落实及处置成效，精准识别系统性风险，搭建风险信息平台实现动态监控。同时为业务部门提供专业培训与支持，优化管控流程，推动风险管理与业务发展深度融合，防范各类合规及运营风险。

# 审计监督部门

审计监督部门以独立客观视角履行监督职责，为风险管理体系有效性提供最终保障。围绕公司战略与经营重点，制定审计计划，对前两道防线工作成效、制度执行、风险处置结果开展全面核查评估。重点排查体系中的制度漏洞、流程缺陷及责任落实不到位等问题，深挖潜在重大风险隐患，精准揭示薄弱环节。通过出具审计报告、提出整改建议，督促限期闭环整改，跟踪整改成效，推动优化风险管理与内控机制，为管理层决策提供参考，持续提升整体风险管控水平。

# 风险管理制度

# 内控合规

津投城开将法律审核作为内控合规体系的核心抓手，建立覆盖经营全流程的三项法律审核机制，筑牢合规经营法治防线。审核工作聚焦核心业务场景，一是合同法律审核，对各类业务合同的合法性、合规性及风险点全面核查，防范履约纠纷；二是重大决策法律审核，为经营发展关键决策提供专业法律意见，保障决策合法合规；三是规章制度法律审核，确保公司制度与现行法律法规衔接一致。通过标准化审核流程与专业把关，强化全员合规意识，防范法律风险，为企业合规运营提供坚实法律支撑。

三项法律审核是国务院国资委成立以来特别强调并重点推进和考核的管理工作，是国有企业法律顾问最基本的工作，也是预防和控制法律风险的基础性工作，必须抓紧抓牢抓实。津投城开深刻认识其战略意义，始终将三项法律审核抓紧抓牢抓实，建立全流程、全覆盖的审核机制，将100%审核要求深度嵌入三大核心事项全流程，形成事前防范、事中控制、事后复盘的闭环管理体系。

重要决策环节严格落实合法性前置审核，对于投融资、资产重组、关联交易、重大项目落地等影响企业发展全局的重要决策，必须前置法律审核程序，由法律顾问出具专业法律意见，全面评估决策的合法性、合规性及潜在法律风险，为决策层提供科学依据，从源头规避违法违规决策行为，保障决策的科学性、合法性和可行性，护航企业战略落地与可持续发展。

# 重要决策

规章制度环节聚焦制定、修订、废止全流程，审核条款合规性与实操性，保障制度体系依法健全。覆盖治理结构、业务流程、内控管理等全领域，确保制度与《公司法》《证券法》等法律法规及监管要求保持一致，同时兼顾企业经营实际需求，避免因制度漏洞引发合规风险，为企业运营提供清晰的行为准则和制度保障，推动管理体系规范化、标准化。
