# 肩负数字化转型使命，领略电科数字发展之路

# 公司概况

电科数字是行业领先的数字化产品和解决方案提供商，主要面向金融、大型企业、党政与公共服务、运营商和互联网等重点行业客户，提供安全可信的物联感知、智能计算、云网融合、网络安全、应用上云、业务数字化、业务智能化等产品、解决方案与服务，业务覆盖从数智底座到智慧场景的主要环节。公司通过深入推进大数据、人工智能、物联网络等新一代信息技术与业务融合创新，持续迭代行业数智化架构体系，打造行业数智化解决方案，提供云-边-端一体、算力-数据-AI协同的总体解决方案供给能力，赋能行业客户数智化转型升级。

# 发展历程

初创探索

1990-1999

1990 年，公司成立，以产业化和市场化为导向，整合了 32 所下属华东电子技术服务公司等三家公司。1994 年，公司向社会公开发行 2000 万股，募集资金 6000 万元，成为国内 IT 行业第一股。主营业务为 EC 电脑、软件开发和国外产品代理。

转型发展

2000-2009

2000 年起，公司开始业务转型，围绕网络、服务器、存储、数据中心等新兴领域发局系统集成和技术服务，探索体制机制创新，采用公司控股、管理团队持股的模式，先后成立了华讯网络、华存数据、华东系统、华誉维诚等公司。

整合升级

2010-2019

2010 年，公司开始实施业务整合升级，启动了第一次重大资产重组，收购了华讯网络 91% 股权，使公司的综合实力得到极大提升。2013 年公司又以现金收购华东系统 45% 和华宇电子 100% 股权。在新战略指引下整合升级，创新发展。

数字化发展

2020 至今

2021 年，公司明确新的战略定位，通过数字化、网络化、智能化新一代信息技术与名行业深度融合的行业数字化整体解决方案，打造行业数字化整体解决方案头部企业。公司启动实施重大资产重组，收购柏飞电子 100% 股权，并实施第二期股票期权激励计划。

# 公司信息披露基本原则

公司和相关信息披露义务人应当根据法律、行政法规、部门规章、其他规范性文件、上市规则等，及时、公平地披露信息，并保证所披露信息的真实、准确完整，简明清晰，通俗易懂，不得有虚假记载、误导性陈述或者重大遗漏。

公司信息披露要体现公开、公平、公正对待所有股东的原则。公司和相关信息披露义务人披露的信息应当同时向所有投资者披露，不得提前向任何单位和个人泄露。但是，法律、行政法规另有规定的除外。

# 缺乏开源治理实践经验

1. 软件供应链安全与软件开发交叉环节治理，治理逻辑复杂，缺乏可参考的实践案例，单方面的治理达不到预期效果；  
2. 技术更新迭代速度过快，新型技术下的新兴风险应对策略，例如开源AI大模型可能带来的风险挑战。

# 传统技术能力覆盖不足

1. 传统依靠源码级的组件风险识别和管控，难以覆盖企业复杂的开发及生产部署场景；  
2. 开源组件安全领域的知识库储备不足。

# 安全价值难以明确度量

开源治理是一个长期可持续的治理流程，短期投入，难以看到理想效果；

# 企业组织层级支撑资源不足

开源治理需企业自上而下的支持，如果治理层面支持不足，相关组织权责不明，可能就会导致开源治理工作推行受阻；

# 采购管理

![](images/181cf806eaac667d4574aed794b3a07d961646ac73b52719651c089f18e7ef0e.jpg)

为优化公司采购流程，强化采购管理，公司依据《中华人民共和国招标投标法》及其实施条例等相关法律法规，特制定采购控制规定，旨在完善采购运行机制，确保采购活动公开、公平、公正，提高采购效率，降低采购成本。

\- 负责组织制定、修改采购管理规定，并监督、检查采购管理规定实施情况

# 专项采购

- 各专项项目组：负责实施专项项目的采购  
- 各业务部门：负责实施经营项目的采购  
- 信息系统管理部门：负责实施 IT 类固定资产、办公用品及相关服务的采购  
- 人事行政管理部门：负责实施非 IT 类固定资产、办公用品及相关服务的采购  
- 其他产品和服务的采购由需求部门实施采购

采购管理职责

为促进公司与供应商之间的健康合作，确保阳光采购、杜绝任何形式的贪腐行为，以保障采购的廉洁性和合法性，公司加强对采购人员行为规范的管理，加强培训，以最终实现提高采购效率、降低采购成本，实现与供应商的共赢发展。

采购人员应严格按照采购控制规定进行采购，采购完成后及时进行备案并确保备案材料真实、齐全

若采购人员违反采购控制规定进行采购或没有及时备案导致采购资料丢失或损毁的，第一次由部门负责人进行批评教育，若再发生类似事件，按严重程度给予采购人员降职、降薪、或予以辞退

采购人员不能接受供应方任何形式的馈赠、回扣或贿赂；若因严重失职或违反本规定作出不适当行为的，给予辞退。给公司造成损失的，应赔偿公司损失，情节严重涉及违法犯罪的，提交司法机关处理

# 供应商评定

![](images/8dd8adb20b4b6b6259ff20d2b9b3b014f91a0df83e2cdc7e34be9742559b1884.jpg)

公司每年定期组织专业团队对合格供应方进行跟踪评定，并填写《供方业绩评定表》，按百分制评价，质量评分占50%、交货期占20%、价格占20%、售后服务占10%。总评分低于60分（或质量评分低于38分），将取消其合格供应方资格，以确保公司采购的优质与高效。

- 供应方提供的产品和服务须符合国家现行质量、环境和职业健康安全规范、标准的要求，产品质量和管理体系通过认证，并保持有效  
- 供应方的产品和服务特性、价格、信誉和交货情况以及及时处理质量问题的能力较高，有优良的售后服务体系  
- 产品和服务经试用或参照相关用户使用经验和评价，证明其产品和服务具有较好的使用业绩  
- 供应方为长期供货单位，产品质量稳定，能提供产品合格证、质保书、使用说明书以及检验和试验报告

# 平等雇佣

公司坚持以人才带动企业发展，积极拓展人才的获取渠道与途径，通过多种方式持续开展人才储备工作，努力打造优秀的业务团队以及专业的技术团队，以人为本全面加强公司综合实力。同时，公司尊重并保护员工的合法权益，致力于打造和谐稳定的劳工关系，进而凝聚员工力量，不断夯实公司发展基石，全力保障公司用工。

公司确保在工作中不侵犯国家法律所规定的员工基本权益，保障员工拥有平等机会，避免员工受到任何形式的歧视，保护员工个人信息和隐私。公司始终恪守公平公正用人原则，公司选用人才不以应聘人员的性别、年龄、国籍、民族、宗教信仰、肤色、语言、户籍所在地等与工作无关的个人特征作为标准做出对应聘人员是否招聘依据。

公司严格遵守《中华人民共和国劳动法》《禁止使用童工规定》《中华人民共和国未成年人保护法》等法律法规的规定，不雇佣、也不支持使用未满16周岁的人员。

公司已建立《员工招聘及录用管理规定》《员工劳动合同管理规定》《员工薪酬和绩效考核制度》《员工手册》

《员工考勤和假期管理规定》《女工劳动保护管理规定》等相关制度文件，明确规定了员工在劳动报酬、工作时间、各类假期、社保福利等方面的权益。

# 绿色办公

公司积极倡导绿色办公理念，通过多种创新举措推动节能降耗与降本增效。公司建立电子化、网络化办公模式，充分利用现代信息技术，减少办公纸张使用，实现无纸化办公，从而降低资源消耗和环境污染。同时，公司还加强办公区域的节电节水管理，倡导低碳生活方式，为发展低碳经济贡献力量。

- 空调温度设置夏季不低于 26 度，冬季不高于 20 度  
- 下班必须关闭空调、电脑、饮水机、打印机等设备电源  
- 微波炉、碎纸机等间歇性使用，设备用时开启，用完即关闭电源

- 设置单面打印废纸回收盒，提倡纸张再利用

# 能源利用

电科数字高度重视能源管理工作，严格遵守《中华人民共和国节约能源法》等相关法律法规，秉持绿色发展理念，持续推进能源管理科学化发展，通过设备的更新换代、技术的创新升级、员工的意识提升等，切实履行能源节约与绿色发展责任，向股东、合作伙伴以及社会各界等利益相关方展示公司在节能降耗方面的积极努力。2026年4月，公司通过ISO50001能源管理体系认证。
