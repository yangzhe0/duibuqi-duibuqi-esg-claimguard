# 治理架构

良好的治理架构是公司高质量发展的基础，绿岛风严格按照《公司法》《证券法》《上市公司治理准则》《深圳证券交易所创业板股票上市规则》《深圳证券交易所上市公司自律监管指引第2号——创业板上市公司规范运作》等相关法律法规的要求，制定《公司章程》及其他内部控制规章制度，持续完善公司股东会、董事会等治理架构，形成职责明确、有效制衡、高效运作的组织治理架构，以保障公司各项生产经营活动的有序开展。

# - 取消监事会

报告期内，为全面贯彻落实最新法律法规和监管规定要求，进一步规范公司运作机制，完善公司治理结构，公司根据《公司法》《上市公司章程指引》及《深圳证券交易所上市公司自律监管指引第2号——创业板上市公司规范运作》等最新法律法规和规范性文件的要求，不再设置监事会，《监事会议事规则》相应废止，公司各项制度中涉及监事会、监事的规定亦不再适用。监事会职能调整后，公司对《审计委员会工作细则》进行了修订，进一步明确并细化董事会审计委员会的职责权限，确保其依法合规履行原由监事会承担的相关职权，有效保障公司治理结构的规范运作。

# - 制度的修订与制订

报告期内，公司根据《公司法》《深圳证券交易所创业板股票上市规则》《深圳证券交易所上市公司自律监管指引第2号——创业板上市公司规范运作》等相关法规的最新规定，结合公司实际情况，完成对《公司章程》及多项会议议事规则、工作制度、管理制度等的修订，同时制订了《舆情管理制度》《信息披露暂缓与豁免管理制度》《董事、高级管理人员离职管理制度》《董事和高级管理人员所持本公司股份及其变动管理制度》《董事及高级管理人员行为规范》《控股股东和实际控制人行为规范》等制度。

# 三会运作

# - 股东会

公司严格按照《公司法》《证券法》《上市公司股东会规则》等相关法律法规和规范性文件以及《公司章程》《股东会议事规则》等相关规定召集、召开股东会，充分尊重全体股东，确保全体股东对公司重大事项的知情权、参与权和表决权，并按照监管要求发布上述股东会的决议公告及法律意见书。

# - 董事会

公司依法设立董事会作为公司的经营决策机构，依据《中华人民共和国公司法》《中华人民共和国证券法》《上市公司治理准则》以及《公司章程》《董事会议事规则》等相关法律法规和规范性文件的规定，履行董事会及董事职责，提高董事会规范运作和科学决策水平。公司董事会由5名董事组成，包括非独立董事3人，独立董事2人。

# 供应商管理

绿岛风重视与供应商的交流，保持良好合作关系，实现互利共赢、共同发展。

- 对于有潜在合作意向的供应商，公司通过资质审查、样品检测、实地走访等多方面评审合格后与其确立合作关系并签订年度采购框架合同。  
- 公司生产部门制定生产计划，计划部门通过ERP系统进行MRP（物料需求计划）运算得出相应物料的采购需求。对于钢材、塑料、铜质漆包线等询价类物料，采购需求经审批通过后，公司根据采购需求量进行询价，确定供应商及采购价格后下达采购订单；对于电子元器件、电机、五金塑料制品、包装材料等非询价类物料，公司按采购需求数量及先前已确认的采购价格直接生成采购订单。供应商将货物送达公司后，公司根据质检方案对物料进行检验，检验合格后予以入库。  
- 公司与供应商按照框架合同所约定的结算方式进行货款结算。

# 绿色办公

绿岛风倡导“节约能源，从自身做起”的理念，推崇低碳生活方式，要求员工深化绿色办公的理念，形成良好的节约习惯。公司引入了外部专业的6S培训与管理，通过常态化的不定期检查工作环境的方式考核员工的6S工作效果，压实各位员工的环境管理责任。

- 倡导节约用电 办公区域统一做到“人走灯灭”，在每个工位的显示器上张贴“人离关显示器”标签，减少待机耗电。  
- 严格用水管理 及时关闭关紧水龙头，通过加强办公区、生活区的设施维护管理，杜绝“长流水”的现象。  
● 推行无纸化办公 公司提倡双面打印、不重要的文件反面利用，积极推行电子化办公。  
● 推动可持续消费 公司提倡少用塑料袋、一次性筷子。  
- 推广垃圾分类 公司办公区、生活区配备垃圾分类设施，让员工积极参与垃圾分类，养成良好习惯。

# 节能减排

绿岛风基于国家近年来关于加快构建清洁低碳安全高效能源体系的战略目标，秉持从自身做起的原则，研究并适行与发展理念相一致的经营、非经营性活动，主动拥抱国家的双碳战略，为我国实现“碳达峰、碳中和”贡献力量，同时树立企业良好社会形象。

# 员工关怀保障

# ● 制度保障

公司建立包括招聘制度、培训制度、薪酬制度、绩效制度、退休制度、福利制度等在内的多项人力资源管理制度，保障员工的合法权益。

# - 薪酬福利

公司遵循同工同酬原则，坚持效益导向，兼顾效率与公平、激励与约束相结合，关注长远，员工薪酬与个人绩效和企业效益紧密联动，构建包含绩效奖金、津贴补贴等的薪酬与福利体系。公司根据法律法规为员工购买五险一金，覆盖比例为100%。

# - 免费食宿

公司为全体员工提供住宿服务，免宿舍管理费及住宿费；为工厂员工提供免费自助早、中、晚餐，为夜班员工提供免费夜宵。

# - 免费体检

公司为员工报销入职体检费用，为在职员工定期组织免费体检。2025年公司组织职检208人次，普检549人次。

# - 在线问卷调查

公司充分尊重员工的生活权益，2025年公司就员工的利益相关问题，如节日礼品、饭菜样式、员工活动满意度等方面进行问卷投票调研，并根据反馈结果予以分析、总结、采纳并公示，提高员工的参与感和归属感。

# ● 举办年会活动

公司每年于春节放假前夕组织全体员工参与年会活动，进行抽奖，并发放形式多样的年货、礼品。
