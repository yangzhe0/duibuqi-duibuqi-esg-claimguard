# 铸 “辰” 品，以安心品质守护消费信赖

品质是食品企业的生命线，我们始终坚守舌尖安全底线，让优质产品触达更多消费者。我们持续完善质量管理体系，福建漳州和江苏南京两大生产基地均通过 ISO 9001 质量管理体系认证，将质量管理贯穿产品全生命周期，并在量贩零食板块搭建“安·质严选”食品安全管理体系，确保产品各环节都符合安全与品质要求。我们通过创新研发持续提升核心竞争力，根据业务板块特点及需求搭建创新管理体系，高效、有序开展研发创新活动。2025年，在量贩零食业务板块，打造“好想来超值”与“好想来甄选”两大自有品牌系列，推出单瓶售价仅 0.6 元的千岛湖水源的天然饮用水、系列无糖茶、独家风味玉米片、原切薯片等产品，迎合不同消费者需求；在食用菌业务板块，获评“国家种业阵型企业（阵型：破难题阵型，物种：食用菌）”，累计获得国家植物新品种权 6 项、福建省非主要农作物品种认定 16 项。

# 守“辰”规，以规范治理筑牢发展根基

规范透明的企业管治是企业可持续发展的根本保障。我们建立规范的治理架构和科学的议事规则，持续完善内部控制与风险管理体系，恪守商业道德，为集团高效运作、健康发展提供坚实保障。我们积极推动以“数智驱动、引领未来”为核心理念的数字化转型，明确三阶段实施路径，以七大核心系统领域为支点，全方位提升数字化水平。2025年，客服工单系统实现日均人效效率提升94.83%，研发效能平台实现发布效率提升81.25%。

# 绘 “辰” 绿，以低碳发展共筑永续未来

绿色发展是高质量发展的底色，我们积极响应国家“碳达峰”“碳中和”目标，积极推进节能减排、污染防治、循环利用等工作，制定能源使用效益、温室气体排放等环境管理目标，科学规划减排路径，将绿色理念深度融

入生产运营与供应链管理全过程，以实际行动守护生态环境，推动企业与自然和谐共生、协同发展。我们高度重视种质资源保护与利用，建有专业种质资源库，配备先进保藏设备，被评为“农业农村部食用菌育种重点实验室”，并建立“中国菌物学会万辰生物服务站”，守护珍贵食用菌基因资源。

# 践 “辰” 诺，以责任担当传递温暖情怀

企业发展离不开社会的滋养，我们始终把社会责任放在公司发展的重要位置，践行上市公司使命，承担社会责任，积极开展各项社会公益事业。我们积极参与乡村振兴事业，与福建省光彩事业促进会联合设立“万辰·光彩基金”，每年捐赠500万元，用于乡村振兴和贫困帮扶；携手多方打造“好想来音乐教室计划”“暖流行动”“好想暖暖过冬天”等公益品牌活动，为乡村儿童送去温暖关怀。此外，我们通过公益捐赠等方式，助力残疾人群体改善生活质量和青少年健康成长成才。2025年，我们向漳州市残疾人联合会捐赠30万元，向福建省青少年发展基金会捐赠100万元，向江苏省慈善总会捐赠300万元。

未来，我们将继续以规模与效率双轮驱动，坚持可持续发展理念，持续完善可持续发展管理体系，在产品品质上更求精进、在公司治理上更趋规范、在绿色发展上更为坚定、在社会贡献上更显担当，着力打造兼具商业价值与社会价值的责任标杆，携手各利益相关方共赴可持续发展新征程，共创美好新“辰”光！

# 走进万辰集团

福建万辰食品集团股份有限公司 2011 年成立于福建漳州，2021 年在创业板上市（股票代码：300972），主营涉及量贩零食和食用菌工厂化种植两大板块业务。其中，公司 2022 年正式进入量贩零食行业，于 2022-2023 年先后整合了五大区域龙头品牌，实现了供应链与品牌的统一。通过“规模扩张”与“能力建设”的双轮驱动，形成了“前端密度 + 后端效率”的协同效应，截至 2025 年底总门店数量超 1.8 万家，门店网络遍布全国 30 个省（含自治区、直辖市）；全国设立 48 个常温仓库及 9 个冷链冷库，拥有超百万平方米现代化物流仓和数字化供应链系统，有效保障了经营效率的稳步提升和单店盈利模型的可持续性，构筑公司的核心竞争壁垒。食用菌业务现有福建漳州和江苏南京两大生产基地，以现代生物技术为依托，采用工厂化方式生产食用菌，为消费者提供“绿色、环保、安全、优质”的食用菌产品。食用菌日产能达 382 吨，位于国内同行业前列。2025 年 8 月入选中国民营企业 500 强榜单，同时入选 2025 年中国服务业民营企业 100 强榜单。

# 研发与创新

# 治理

万辰集团将研发创新视为提升核心竞争力、实现可持续发展的重要根基，根据量贩零食和食用菌两大核心业务板块的业态特性与发展需求，建立独立运营的创新管理体系，确保研发创新活动高效、有序开展。

量贩零食业务板块，由商品中心负责新品开发工作。我们以自有品牌商品差异化为核心理念，对产品的包装形式、名称、工艺、设计及配料表等方面设立了创新性要求，并配套建立了涵盖消费者测评、比价管理、首单流程、建品规范、试销管理及新品准入的全环节 SOP 体系，形成了从创意立项到市场落地的全套新品执行链路与管理标准。

食用菌业务板块，我们建立了权责清晰、协同高效的管理架构，并制定《研发管理制度》，规范研发全流程管理，该制度适用于集团研发中心、各生产工厂及下属子公司，内容涵盖日常基础研究项目和专项研发项目两类核心业务。此外，通过设立专项研发经费、实施薪酬倾斜与奖励、对核心技术骨干配套股权激励等方式为研发创新提供资金保障。

# 产品营养与健康

近年来，随着人们健康意识的提高和生活方式的改变，健康食品成为更多消费者的选择。万辰集团始终以消费者健康需求为核心，把握健康食品产业发展机遇，持续打造绿色、安全的健康产品矩阵。

# 量贩零食业务板块：精简配料、营养升级

我们始终坚持围绕“安心、省钱、好吃”理念推进自有品牌的产品开发。其中，“安心”不仅要求产品品质对标行业头部水平，更在营养健康方面针对不同品类制定细分标准，以“精简配料、营养升级”推动产品持续迭代升级，持续守护消费者的营养与健康。

# 供应链源头管理

与核心供应商、原料商建立“健康原料联合研发机制”，溯源到原料起点，优先选购更为优质、非转基因、有机认证、优质植物蛋白等天然原料。

# 产品配方升级革新

对标现有配方或市场明星产品进行配方升级，实现减糖、0反式脂肪酸添加、0防腐剂添加等，并获得第三方机构的有机认证。

# 产品矩阵完善

根据目标消费人群的健康需求，针对性补充开发营养强化产品。

# 数字化生命周期管理

将产品健康指标的消费者反馈纳入产品周期评估体系，回收定性与定量反馈，对不符合健康指标要求的产品进行下架或产品升级。

# 知识产权保护

我们制定了完善的知识产权的管理制度，规定了公司商标、著作权等知识产权在品牌产品、包装、广告宣传等方面的使用规范；搭建精细化知识产权资产台账，对现有专利、商标等实施全生命周期管理，及时完成年费缴纳、续展等维护工作，确保知识产权资产有效存续；对核心品牌标识实施全面保护，通过持续创新与知识产权布局保障公司可持续发展。2025年，公司未发生重大知识产权纠纷。

# 产品质量及安全

# 治理

# 循环农业

公司将生态优先、绿色发展的理念贯穿于生产全过程，实现从“农业废弃物”到“食用菌”再到“有机肥/燃料”闭环。

生产原料主要采用玉米芯、米糠、麸皮等农业下脚料，不仅有效降低生产成本，更实现了对秸秆等废弃物的资源化利用，从源头减少废弃物产生。

对生产后的菌渣进行充分循环利用。一方面，金针菇的废菌料可应用于公司自身白玉菇、蟹味菇的栽培，实现内部资源循环；另一方面，对外销售作为生产有机肥的原辅材料或用作生物燃料再利用，有效解决了传统农业废弃物污染问题。

公司建立完善的健康与安全制度体系，涵盖《安全管理奖惩制度》《事故管理制度》《安全教育培训制度》《安全警示标识与安全防护管理制度》《安全隐患排查管理制度》《危险作业管理制度》《消防安全管理制度》，同时配套《工伤管理制度》《劳动防护用品管理制度》《高低温作业管理制度》《相关方管理制度》《燃气站及管道安全管理制度》《电动车充电安全管理制度》等专项制度，形成覆盖安全奖惩、教育培训、隐患排查、危险作业、工伤管理等全方位的管理体系，为员工职业健康与生产安全提供坚实制度保障。

# 安全能力提升培训

公司制定《安全教育培训制度》，建立覆盖全员、全场景、全流程的安全生产培训体系，实行新进员工三级安全培训、转岗复工培训、“四新”专项培训、特种设备及特种作业人员持证培训、安全管理人员专业培训、在职人员月度定期培训，系统落实岗前、在岗及转岗等各环节的安全教育与考核，确保各层级、各岗位人员具备必要的安全知识与操作技能。

此外，依据 2025 年度安全培训计划，公司针对作业安全分析（JSA）、事故管理、生产安全、危险源识别与管控、急救安全及消防安全等核心课题开展系列安全培训，全面提升员工的安全法规意识、风险识别与应急处置能力，系统性强化公司的安全生产管理体系。

# 案例 开展挂牌上锁（LOTO）专项安全培训

为强化设备作业安全管理，福建漳州基地组织开展挂牌上锁（LOTO）专项安全培训。培训围绕 LOTO 全流程管理展开，覆盖术语定义、典型事故警示、相关法律法规要求、适用范围界定、关键操作步骤、专用工具使用规范及 LOTO 程序编写等核心内容，帮助员工全面掌握设备维修、保养等作业前切断能量源、上锁挂牌、警示防护的标准流程，从源头杜绝设备意外启动、能量误释放等安全隐患，切实保障一线作业人员人身安全与生产运营稳定。

# 安全应急管理

公司构建多领域应急管理体系，制定《安全生产事故应急预案》《突发环境事件应急预案》《工伤管理制度》等专项制度，覆盖火灾爆炸、中毒、环境污染、工伤事故等各类应急场景，明确现场救援、伤员送医、事故上报、调查处理的标准化应急响应流程。同时，规定一线部门每年开展4次、后勤二线部门每年开展2次应急演练，同步落实消防设施维护保养、现场急救药箱配备、120联动机制等工作，通过“制度+演练+保障”全方位提升应急处置能力。

2025 年，我们开展差异化应急演练，福建漳州基地组织无预警疏散演练 30 场，灭火器水带实操演练 38 场；江苏南京基地组织中型消防演练 2 场，部门 / 班组演练 36 场，有效提升员工的应急处置能力。

# 相关方安全管理

公司高度重视相关方安全生产管理，将相关方安全纳入企业整体安全管理体系，依据《相关方管理制度》实施全流程、标准化管控，明确采购部、安环部、业务归口管理部门职责分工，形成协同管理机制。同时，要求相关方同步落实现场消防、临时用电、环境管理等各项要求，确保相关方作业行为全程合规，构建企业与相关方协同联动的安全生产防线。2025年相关方单位共计53家，均严格落实全流程安全管理要求。

# 作业前

由采购部完成相关方资质审查、人员信息登记，审核合格后签订《安环协议书》《法人委托书》《承包商作业许可证》，未完成手续者严禁入厂作业；安环部对所有相关方人员开展系统性安全告知与教育培训，做好培训记录归档。

# 作业期间

业务归口管理部门每日开展开工前安全提示、现场全程监工，安环部常态化督导施工现场规范落实，对危险作业严格执行作业票审批制度，要求相关方严格遵守公司安全作业标准、劳动防护及现场管理规定；对作业过程中发现的违规行为及时制止、督促整改，按规实施考核处罚。

# 安全事故及工伤应对

万辰集团建立标准化、全流程的安全事故及工伤应对体系，严格遵循“预防为主、快速响应、科学调查、闭环整改”原则，明确事故分级标准、部门职责与处理流程，全面保障员工健康与安全。

# 事故预防与控制

公司对新进员工开展三级安全培训，转岗 / 复工员工实施岗前培训，特殊工种需经专项训练考核合格后方可上岗，培训记录统一归档。严格管控 “三违” 行为，明确全员举报义务，对违规人员开展教育惩戒，屡次违规者追究部门负责人连带责任；同时推行属地自查自纠，要求员工及时上报并消除隐患，从源头降低事故风险。

# 事故报告与救援

事故发生后，最先发现者立即向部门负责人、安环部报告，涉伤人员同步协调送医；事故部门需在规定时限内书面告知相关部门事故详情，轻微伤及以上事故、火灾事故及时上报管理层，死亡及特别重大事故按规定上报属地监管部门。救援阶段严格执行应急预案，火灾事故组织疏散灭火，工伤事故优先救治伤员；重大事故妥善保护现场及证据，确需移动物件时做好标识与记录。

# 事故调查

按等级分层推进，轻微伤或一般事故由责任部门提交调查报告，安环部协同制定预防措施；轻伤及以上、重大及以上事故成立专项调查组，报告报管理层审批；死亡及特别重大事故配合政府部门调查。所有事故严格落实“四不放过”原则，推动整改措施落地，防范同类事故重复发生。

# 事故奖惩

对事故预防、救援有功的个人或团队予以表彰奖励；对违规操作、隐患整改不力、瞒报漏报等导致事故或处置延误的行为，视情节追究相关人员及部门负责人责任并予以处罚。

# 事故申诉

确保事故处理公平，员工对事故处理结论有异议的，可通过所在部门向公司管理层提出申诉，由指定部门统筹核查处理，充分保障员工合法诉求得到公正回应。

# 职业健康

公司高度重视职业健康管理工作，严格遵循《职业病防治法》等法规要求，制定《职业健康管理制度》，明确安环部、人力行政中心、采购部、财务部及各生产部门的职责分工，构建覆盖危害预防、过程防护、检测评价、健康监护、设施管理的全流程职业健康管理体系，全方位保障员工职业健康权益。

# 职业病危害前期预防

公司对生产性建设项目严格落实职业卫生“三同时”管理，开展职业病危害预评价与控制效果评价；优先采用低危害的新技术、新工艺、新材料，优化生产布局实现有害与无害作业分开，配套建设更衣间、休息间等卫生设施，从源头降低职业危害风险。同时对新上岗员工开展上岗前职业健康体检，杜绝职业禁忌证人员从事相关作业。

# 生产过程 职业健康

公司为职业病危害岗位员工配备合规有效的个体防护用品并监督规范使用；安环部定期组织职业卫生法律法规、急救知识等培训，提升员工自我保护能力，同时通过自动化、密封化等工程技术措施，确保作业场所职业病危害因素浓度符合国家职业卫生标准，同步制定应急预案、配备应急器材，保障作业安全。

# 常态化检测与健康监护机制

公司委托有资质机构按规定开展职业病危害因素检测与现状评价，检测结果及时公布并存档；为接触职业病危害因素的员工统一组织上岗前、在岗期间及离岗前的职业健康体检，费用由公司全额承担，建立健全员工职业卫生档案与健康监护档案。对体检发现的职业禁忌证、疑似职业病人员，及时妥善调岗安置，按规定上报相关情况，并落实职业病危害岗位员工的专项福利待遇，切实维护员工职业健康权益。

# 影响、风险和机遇管理

万辰集团将员工健康与安全相关风险防控纳入企业运营全流程管理，推行作业安全分析（JSA）落实安全风险管控，全员参与风险分析，明确自身岗位每个作业工序存在的风险，开展风险等级评估，形成风险管控清单，明确并不断完善风险控制措施。

以装瓶车间、接种车间、培养车间、化验室、物流仓储等核心生产作业区域为例，各工序开展全维度危险源识别，针对粉尘吸入、机械伤害、高温烫伤、化学灼伤、火灾爆炸等多类型风险，从可能性、暴露频率、后果严重程度等维度进行量化评估，并结合风险时态、状态完成等级划分与重大危险源判定，形成针对性风险控制措施，从源头精准识别安全风险点。基于辨识评估结果，公司实施安全风险分级防控管理，将风险划分为1-5级，对应制定常规管理、重点管控、立即整改、停止作业等差异化管控要求，配套佩戴防护用品、安装防护设施、制定专项方案、推进工程技术改造等管控措施。
