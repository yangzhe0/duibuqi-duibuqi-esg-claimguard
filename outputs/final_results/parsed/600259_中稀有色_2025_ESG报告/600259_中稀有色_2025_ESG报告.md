# 董事会致辞

2025 年，是中稀有色融入中国稀土集团后从“整合适应”迈向“战略转型”的关键一年。我们以习近平新时代中国特色社会主义思想为指导，贯彻新发展理念，践行“资源报国、稀土强国”使命，将 ESG 理念融入企业发展全局，在治理、绿色、创新、社会责任等方面成效显著，Wind ESG 评级从 BBB 级升至 A 级，践行国企高质量发展责任。2025 年公司实现营业收入 58.20 亿元，归属于上市公司股东的净利润 1.28 亿元，同比实现扭亏为盈，并向全体股东合计派发现金红利 50,465,386.50 元（含税），首次实现分红。

# 走进中稀有色

# > 公司简介

中稀有色金属股份有限公司（证券简称：中稀有色，证券代码：600259）是中国稀土集团的核心上市公司，由始建于1953年的广东省冶金厅、1983年成立的中国有色金属工业广州公司沿革而来。2024年1月，国务院国有资产监督管理委员会批复，同意广晟控股将其所持有的广东稀土集团100%股权无偿划转给中国稀土集团，本次股权划转后，中国稀土集团成为公司的实际控制人。2025年12月26日，公司更名为“中稀有色金属股份有限公司”，证券简称为“中稀有色”。

公司是广东省内稀土资源的唯一合法开采企业，截至报告期末，拥有全资、控股企业16家，员工总数938人，主要从事稀土矿开采、冶炼分离、深加工以及有色金属贸易业务，横向构筑“稀土、钨、铜”三大产业布局，纵向打造“矿山开采、冶炼分离、精深加工、贸易流通与进出口”完整的稀土产业链，生产品包括稀土精矿、混合稀土、稀土氧化物、稀土永磁材料等。

# > 产业布局

公司作为广东区域唯一稀土资源合法开采企业，持有目前广东省内获批的全部稀土采矿证，具备稀土全产业链优势。公司拥有稀土全元素分离能力，在中重稀土领域具有突出的竞争优势，是全球重要的中重稀土产品生产企业和供应商。

# 中稀有色业务优势

# 稀土板块

·资源优势：公司拥有广东省内全部3本稀土采矿证，其中新丰稀土矿是全国储量最大的离子型稀土矿山。  
·冶炼分离技术：控股3家南方离子吸附型稀土矿冶炼分离厂，掌握国内最先进的冶炼分离技术。  
·产业链延伸：投资设计年产8,000吨高性能钕铁硼磁性材料晟源公司，并与世界500强企业TDK公司合资成立东电化公司，具备先进的高性能烧结钕铁硼生产技术和装备。

# 钨板块

·钨矿资源：公司参控股广东省内2家钨矿山，其中红岭钨矿已探明钨矿资源量6.4万吨，为国内大型露天开采钨矿山。近期红岭矿区内资源综合勘查项目，已完成第一阶段找矿预测工作。  
·转型升级：通过实施大型专业化白钨资源开发升级，钨板块未来将成为公司新的盈利增长点。

# 铜硫板块

·资源开发：参股广东省大宝山矿，该矿铜、硫、钨、钼资源丰富，拥有华南地区规模最大的铜硫采场和选厂，以及广东省内最大的钨综合回收选厂。  
·绿色发展：致力于打造生态友好、技术一流、效益领先的全国绿色矿山建设示范基地，推动资源开发与环保协同发展。

# 贸易板块

·贸易优势：公司以高质量贸易推动主业发展，建立了健全的贸易风险管控体系，并拥有强大的市场营销团队。  
·历史积淀：依托逾40年的进出口经验，并拥有开展境外业务的平台窗口，国际化布局稳步推进。

# 专题

# 践行国企使命 实现战略转型新突破

2025 年是 “十四五” 规划的收官之年，面对稀土行业错综复杂的国际国内形势、公司改革转型与历史包袱重压下，公司坚持以习近平新时代中国特色社会主义思想为指导，以 “铁” 的意志深化改革，以 “钢” 的韧劲优化布局，以 “火” 的淬炼提质增效，围绕 “价值创造” 核心，打赢 “扭亏增盈、提质增效、破旧立新” 三大战役。

01

# 提质增效

夯实可持续运营“基本盘”

工贸协同，降本增效。公司坚持价值创造导向，深化工贸营销协同，采购端发挥“541”模式优势严控原料成本；销售端采取“长协锁定+动态营销+内外协同”策略，推动主产品销量稳步增长、效益持续提升，同步盘活存量资产及历史库存，资金周转效率显著提高。对内纵深推进全要素成本对标与精益管控，三项费用及融资成本有效压降，各生产单元深挖内潜，物耗水平与生产成本持续优化，集中采购效能不断释放。

深化改革，激活组织。公司高质量完成国企改革深化提升行动，以“瘦身健体”优化管理架构，总部管理人员占比由33%降至19%，专业人员占比提升至81%，人岗匹配度与运行效率明显增强。依托“四专协同”攻坚机制，扎实推进法人压减与亏损治理，资产结构与盈利能力持续改善。深入践行董事会“211”模式，公司治理效能稳步提升，获评“2025年上市公司董事会最佳实践案例”，信息披露保持零差错，为高质量发展筑牢坚实根基。

02

# 产业布局优化

构建绿色低碳“新格局”

资源保障，绿色先行。华企仁居矿完成资源详勘并通过专家评审，为稳产高产提供有力支撑；红岭北部探矿工作有序推进，资源保障能力进一步巩固。华企公司离子型稀土矿生物开采技术实现产业化示范应用，为绿色矿山建设提供新路径，有效减少生态扰动，守护生态环境。

产能升级，链式发展。晟源公司高性能钕铁硼项目产能稳步提升，磁材应用领域持续拓展。红岭公司白钨项目取得关键突破，钨矿资源综合利用技术攻关成功，为构建“稀土+稀有”双轮驱动发展格局奠定坚实基础，推动资源高效集约利用。

03

# 科技创新驱动

锻造绿色发展“硬实力”

绿色技术，行业领先。公司坚持创新驱动发展战略，以技术创新赋能产业绿色转型。兴邦公司攻克高氟矿处理难题，突破5N高纯氧化钇量产及低放射性氧化镥制备技术，构筑差异化竞争优势；富远公司高盐废水零排放技术荣获稀土科学技术二等奖，并入选国资委推广目录；晟源公司突破大尺寸磁体工艺，生产成本显著下降；红岭公司极低品位钨多金属矿绿色高效利用技术入选自然资源部《矿产资源节约与综合利用先进适用技术目录（2025年版）》。多项科技成果荣获省级重要奖项，科研平台实力持续增强，为企业高质量发展注入强劲绿色动能。

# 合规经营

合规管理是企业经营管理的重要组成部分，是内部控制和风险管理的基础。公司以打造从顶层设计到基础执行“一竿子插到底”的合规管理体系为目标，持续完善党委统一领导、董事会审计、合规与风险管理委员会统筹把关、合规部门协调推进、各业务部门及所属企业分工落实、全体员工共同参与的合规管理架构。公司组织全体员工签署《合规承诺书》，明确遵规守法、恪尽职守、强化学习、严格监督等要求，推动合规要求融入业务各环节，逐步形成覆盖全员、贯穿流程的合规责任体系。

公司制定《合规管理办法》，秉持“管业务必须管合规，管合规必须精业务”理念，构建以管理办法为核心、配套制度为补充的“1+1+N”制度体系。聚焦投资管理、合同管理、安全环保等重点领域，强化合规审查，细化决策权限，加强运营监督。定期开展合规评价，分析管理现状及风险，由法律合规部（审计部）监督改进。将合规纳入经营业绩考核，定期评选先进并予以表彰奖励。

公司制定《法律合规审查办法》，建立合规审查前置工作机制，将合规要求嵌入业务流程，明确各部门合规审查职责，压实主体责任，有效防范和控制合规风险。公司每年组织开展重点领域合规检查，重点检查各部门是否存在违反法律法规、行业准则、规章制度及道德规范等情形，并督促落实整改。

# · 治理体系

中稀有色贯彻落实《中国稀土集团有限公司碳达峰行动方案》，深入聚焦“减污降碳”总体要求，推动公司绿色低碳、高质量发展。

公司成立双碳工作领导小组，由公司党委书记、董事长牵头统筹，对碳达峰工作实施统一领导；领导小组下设安全环保部（应急指挥中心）为工作组，负责落实双碳工作领导小组议定事项、制定任务分工方案、跟踪任务落实情况等日常工作；各所属企业依据层级成立配套的双碳工作小组，与工作组协同配合，细化落实各项任务举措，推进碳达峰工作落地。

# - 双碳考核

公司建立健全双碳督察考核机制，将碳达峰相关指标纳入综合评价体系，形成与绩效结果挂钩的激励约束机制。各所属企业每年开展碳达峰水平评估，公司对碳达峰目标任务落实情况进行考核，及时排查问题、提出改进要求并督促整改落实，对工作成效突出的单位和个人按规定予以表彰奖励。

# - 节能降碳意识提升

中稀有色致力于强化员工双碳意识与专业能力建设，针对性开展节能降碳相关培训，依托六五环境日、低碳日、节能周等时间节点，邀请专家进行专题解读、开展科普活动；同时利用网络、微信平台等形式开展线上宣传，营造节能降碳氛围，提升全员节能降碳意识。

同时，公司结合行业特点和需求，组织开展碳排放核算、碳交易等专业化培训，提升相关岗位人员的专业素养与实操能力，持续加强碳排放管理专业人才队伍建设，为公司碳达峰、碳中和目标实现提供坚实的人才支撑。

# · 环境应急管理

# - 隐患排查

公司制定《环境风险排查及隐患治理制度》，采取月度、季度现场排查与不定期巡回检查相结合的方式，对各生产部门、车间开展全面环境风险排查。对排查发现的环境风险与事故隐患，由安全环保部（应急指挥中心）下达整改通知书，严格按照“三定、四不推”原则落实整改。公司建立健全风险隐患排查整治长效机制，规范隐患登记与评估工作，从源头防范化解环境风险，有效预防和减少突发环境事件。报告期内，公司针对环境隐患开展全面排查整治，隐患整改率达100%。

中稀有色重视水资源的合理合规利用，将水资源管理融入生产运营全过程，持续采取有效措施提升水资源利用率，并加强对用水过程的监督检查。

公司积极推进生产用水循环利用，以节水增效促进节能降耗。富远公司采用新工艺技术，实现生产废水回用，通过 MVR 蒸发处理，减少生产废水约 16 万 $m^{3}$ ，生产废水回用率达 70% 以上。兴邦公司通过回收草酸类的产品低电导水洗水，用于回收料产品水洗，每月约节省用水 $600m^{3}$ ；同时将回转窑余热废水回用于草酸镨钕沉淀底水，月回用约 $300m^{3}$ ，有效降低镨钕沉淀用水量与底水加热天然气消耗。

# 影响、风险和机遇管理

为降低研发创新风险，公司从实际经营情况出发，依据《风险控制管理制度》，对风险和机遇进行识别及评估，通过有效识别研发过程中的风险因素，跟踪监测重大风险事件，以降低风险，实现技术创新。

# 风险信息收集

利用各种方法和途径收集、整理公司各项管理活动和经营活动中所有相关的内、外部风险信息，并对风险信息进行筛选、提炼，并及时传达给相关单位及人员。

# 风险评估

通过定性与定量相结合的方式定期对风险进行评估，按照风险评价标准，从风险的可能性、可能的影响程度对识别出的风险进行排序，确定风险的高、中、低等级和管理的优先顺序与策略。

# 风险应对

公司根据不同业务特点确定风险偏好和风险承受度，明确风险点最低限度和不能超过的最高限度，并据此确定风险的预警线及相应采取的策略。

# 风险监测

建立风险监测、预警与报告机制，根据业务领域特点和绩效指标，结合行业水平、实际状况等因素设定相关风险监测预警指标和风险水平预警值，动态显示风险水平和预警。

# 风险管理

定期对风险管理工作进行自查、检验，及时发现缺陷并改进。

# ·研发激励

公司依据《科技成果奖励管理办法》《创新驱动发展奖励暂行办法》等制度，构建起权责清晰、程序规范的科技创新激励与评审体系。通过设立国家级、省部级科技成果配套奖励，明确差异化奖励标准与兑现原则，对为公司科技创新作出突出贡献的集体和个人予以表彰奖励，充分调动科技人员创新积极性与主动性，助力公司科技创新水平和核心竞争力提升。

同时，公司秉持“效益导向、贡献匹配、公平公正公开”原则，建立研发项目收益分红机制，依据《研发项目收益分红制度》，对成功落地并产生收益的研发项目团队予以分红激励。为保障激励机制公平有效，公司成立由财务、审计、人力资源等部门组成的监督小组，对分红方案实施全过程开展监督。

# 影响、风险和机遇管理

为有效降低产品质量风险，公司制定《风险和机遇应对措施控制程序》《风险评估与机遇分析报告》等制度文件，明确相关管理工作流程及部门职责，实现对各类质量风险与发展机遇的规范化应对。

# 风险识别

对可能存在风险的车间、生产过程和人员存在的风险进行逐一筛选识别，考虑法律、市场、技术、供应商等多方面因素，识别潜在风险点。

![](images/d30ce8b482455ce3151148b9016a176bb73464e299924c555fdadae1f042c482.jpg)

# 风险评估

对识别出的产品风险进行评估, 按照风险的严重度和发生频率评价准则确认风险等级系数, 找出重要风险项目。

![](images/5168ef7c499d6c1d2eed2ca3c823fb2dd9c0a0df880daa02f7b78ea07d516273.jpg)

各部门确定应对风险和机遇采取的措施,采用风险接受、风险降低、风险规避等方法应对,确保风险控制措施的有效性及可行性。

![](images/d9f8fc70e5e18082451597f6139246d24a5247f8e677f11455804d1bc2472773.jpg)

# · 产品召回管理

中稀有色所属企业兴邦公司建立了完善的不合格品管控及退（换）货管理机制，依据《不合格品控制程序》，实现对原材料、半成品、成品等各生产环节不合格品的闭环管理，明确质检部为不合格品判定评审主体，按层级划分质检部、副总经理、总经理的审批处置权限。针对出厂不合格成品，由总经理制定专项处理方案，同时配套规范的《退（换）货管理办法》，规范内外部退（换）货的条件、书面申请流程及多层级审核要求。

# 客户服务

# · 客户服务管理

公司高度重视客户权益保障，制定《销售业务管理制度》，以标准化管理规范销售流程、提升运营效率，实现公司经济效益最大化。

公司围绕稀土产品发展目标与销售需求，多渠道收集、分析客户资料并建立规范客户档案，通过电话沟通、客户走访、信函联系等多元化方式，保持与客户的常态化互动。

同时，公司构建完善客户服务机制，定期开展客户回访与满意度调查，系统收集客户反馈，及时响应诉求，持续优化产品性能与服务质量，以优质产品及服务解决方案提升客户满意度与品牌忠诚度，实现与客户共赢发展。

# · 客户满意度

公司致力于构建长期稳定的合作伙伴关系，为持续提升客户体验，所属企业兴邦公司制定《顾客满意度管理程序》，通过定期开展顾客满意度调查，系统收集并分析顾客反馈信息，识别客户需求，持续优化沟通机制，全面提升客户服务质量。

公司建立直接沟通、满意度调查表等多渠道顾客信息收集机制，由企业管理部（矿产资源部）统一登记、整理客户反馈与投诉并转交质检部分析处置。相关部门依据分析结果制定并落实纠正预防措施，企业管理部（矿产资源部）对相关资料存档管理并定期编制汇总报告，质检部跟踪改进措施的实施效果，及时向客户反馈改进情况，确保客户满意度持续提升。

# · 绩效管理与申诉

# 绩效考核机制

公司制定实施《总部绩效管理暂行办法》，搭建覆盖公司各部门及在职人员的绩效考核体系，分部门、员工两类对象实施月度、年度考核，遵循战略、发展、激励原则，按部门及总助级、中层、专业人员等层级设置差异化考核指标与评定规则，明确特殊人员考核要求。公司建立规范考核实施流程，设置绩效回顾、目标调整等环节，考核结果与绩效薪酬直接挂钩，作为员工职级调整、晋升评优、末等调整及中层管理人员岗位聘用的重要依据，以健全的激励约束机制激发员工活力，推动公司发展战略落地。

# 申诉与反馈机制

中稀有色建立完善的绩效申诉机制，切实保障员工合法权益。若部门或个人对绩效评估结果存在异议，可在获知结果后5个工作日内，以书面形式向人力资源部提交申诉书；人力资源部（党委组织部）接到员工申诉后，应在3个工作日内作出是否受理的答复；受理员工申诉后，组织开展调查、核实工作，并在7个工作日之内形成正式的处理意见；未能协调处理的员工申诉，由公司党委作出最终决定，以此保障绩效评估工作的公正、透明与有效开展。

# · 福利待遇

# 福利休假

中稀有色高度重视员工福利保障，构建多维度全方位福利体系，切实维护员工合法权益。法定保障上，严格按规定足额缴纳五险，同步推行补充医疗保险、企业年金制度，形成“基本+补充”双重保障格局，筑牢员工保障防线，增强归属感与安全感；福利激励上，奖金福利与员工绩效、公司效益挂钩，完善休假制度并明确各类假期标准，有效激发员工工作活力。同时，配套员工食堂、爱心理发屋等生活设施，增设娱乐区域并定期组织文体活动，常态化开展健康体检与安全培训，兼顾员工生活、休闲与健康需求，打造有温度的福利体系，切实履行企业社会责任，营造多元化、平等包容的工作环境。

# 影响、风险和机遇管理

# · 风险管理机制

为降低生产运营中的安全与职业健康风险，公司制定《安全生产管理办法（试行）》，由安全环保部（应急指挥中心）牵头组织安全风险与危险源辨识、评估工作，督促落实风险分级管控及重大危险源管理要求，指导各部门及所属企业开展全流程风险管理，切实应对员工安全健康相关风险与机遇。

公司每季度召开风险研判会，重点研判下一季度重大风险，组织各所属企业结合季节特征、重要节点及生产经营实际，梳理识别本单位主要风险及公司级管控风险点；同时对各所属企业隐患整改情况开展复核检查，核查安全管理措施落实情况与整改成效。

建立全面风险识别机制，定期辨识生产过程中的危险有害因素，覆盖法规更新、工艺调整、新设备投用等场景，确保及时识别职业健康与安全生产领域的潜在风险。
