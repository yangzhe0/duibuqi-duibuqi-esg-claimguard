# 董事长致辞

2025 年，是 “十四五” 规划收官之年，亦是常山北明提质增效、加速转型升级的关键节点。这一年，面对蓬勃涌动的数字经济浪潮，行业深刻变革与时代发展机遇交织共进，公司始终保持坚定战略定力，锚定高质量发展航向，以自主创新为引擎破解发展难题，携手全体员工与各界合作伙伴笃行奋进，交出了一份凝结全体常山北明人智慧与汗水的高质量发展答卷。

# 这一年，我们以规范治企为纲，筑牢发展根基。

公司坚持党建引领与现代企业治理深度融合，以党的政治建设为统领，统筹推进思想建设、组织建设、作风建设、纪律建设与制度建设，以党建聚力铸魂、坚守初心使命；持续完善法人治理结构，明晰权责运行边界，年内修订相关制度15项，推动决策科学化、制度化、规范化；构建全方位、全流程合规风控体系，牢牢守住经营发展底线，以规范透明、高效稳健的治理效能，为企业长远健康发展保驾护航。

# 这一年，我们以责任立企为要，赋能美好未来。

公司坚持以科技创新为核心引擎，完成研发投入 25,244.53 万元，成功推出政务服务大模型、AI（人工智能）数字人、计量大模型管理平台等创新产品，以创新实力激活高质量发展内生动力；始终坚守客户至上理念，凭借专业可靠、场景领先的解决方案为客户创造长期价值，主动携手产业链上下游伙伴，构建开放共赢、安全可控的产业数字生态；持续完善人才发展体系，全年吸纳就业 438 人；积极投身公益事业，2025 年志愿者累计参加活动时长达 200 小时，用实际行动践行企业社会责任，传递常山北明力量。

# 这一年，我们以绿色兴企为脉，引领绿色发展。

公司坚守生态优先、绿色发展理念，持续健全环境管理体系，完善环保制度与管控流程；积极响应国家“双碳”目标，建成投产100兆瓦风电项目；累计建成装机总量14.9兆瓦分布式光伏电站，应用在高校、交通、工业厂房等多个场景；建成投产常山五金机电数智中心新能源电动汽车充电站，为园区内货运车、公务车、通勤车提供稳定能源保障，助力绿色低碳出行；完善园区配套，提升综合服务能力，助力园区打造绿色低碳示范园区；全面推行低碳运营、节能增效模式，打造京津冀绿色算力标杆——常山云数据中心，助力企业与自然和谐共生。

# 公司简介

石家庄常山北明科技股份有限公司是常山集团旗下的上市公司，也是石家庄市唯一市属国有控股上市公司。1998年以原石家庄棉一至棉四为基础改制设立，2000年在深圳证券交易所上市（股票代码：000158），2015年7月通过增资扩股，完成了对北明软件有限公司的并购重组。2024年通过资产置换，引入了与软件业务有协同效应的新能源及智慧城市业务，同时剥离纺织业务。现有软件和信息技术服务、新能源等业务，是中国数字经济企业500强和河北省战略性新兴产业领军百强企业。

常山北明全资子公司北明软件是国家规划布局内重点软件企业，是国家工信部认定的信息系统集成及服务大型一级企业，位列中国软件和信息技术服务竞争力百强企业第45位，拥有信息系统建设和服务能力杰出级（CS5）、建筑智能化系统设计专项甲级、电子与智能化工程专业承包一级、CCRC信息系统安全集成服务一级、ITSS信息技术服务二级、数据管理能力成熟度三级等行业顶尖资质。围绕全域城市数字化转型、司法科技、企业数字化转型、金融科技、智慧交通和数字新基建工程等，形成了一系列技术领先的大数据、云计算、区块链、人工智能等综合性IT产品和解决方案，确立了在相关领域的市场优势地位，是华为的核心战略合作伙伴。

在石家庄市委、市政府的坚强领导下，常山北明将大力弘扬“务实、创新、服务、共赢”的企业精神，以市场为导向、以质量为根本、以创新为引擎、以品牌促提升、以服务促发展，围绕主业做大做强，加快成长为中国一流的科技型行业领军企业。

# ESG 治理

常山北明坚持把 ESG 理念融入经营管理与业务发展各环节，持续完善 ESG 管理体系、夯实管理基础、深化实践落地，以负责任的经营行为践行国有科技企业的使命与担当。

# ESG 管理架构

公司建立健全 ESG 管理组织架构，设立社会责任领导小组，作为社会责任工作的核心领导机构，统一领导公司社会责任工作开展；领导小组下设办公室，办公室设在董事会办公室，全面统筹协调公司社会责任日常运营管理工作。

# ESG 管理机制

公司发布《2026年社会责任工作实施方案》，明确年度社会责任工作目标、重点任务、实施路径与责任分工，为公司ESG工作有序开展提供清晰指引和制度保障，推动社会责任理念与要求深度融入公司生产经营各环节。

# 重要性议题识别

公司参照深圳证券交易所《可持续发展报告编制指南》，基于“双重重要性”原则开展重要性议题分析，并对具有重要性的 ESG 议题进行披露。

# 常山北明 2025 年重要性议题分析流程

# 了解背景

了解公司活动和商业关系，解读国家及行业法律法规和监管政策，分析评级标准、同业实践，了解主要受影响的利益相关方以及与利益相关方沟通的方式。

# 建立议题清单

参考《可持续发展报告指引》设置的 21 个议题，结合公司主要业务板块特点、政策标准分析及同业对标，并了解各部门及其受影响的利益相关方关注的议题，汇总形成 22 项重要性议题 $^{1}$ 。

# 评估与确认

邀请内外部专家，共同识别和分析议题的影响、风险和机遇，评估议题的影响重要性和财务重要性，确定议题重要性排序，形成重要性议题矩阵。

# 报告披露

就重要性较高的议题进行重点披露。

结合标准对标、政策分析及同业对标情况，公司识别并筛选出22项议题，其中，3项议题具有双重重要性；1项议题仅具有高度财务重要性；11项议题仅具有高度影响重要性；7项议题既不具有高度财务重要性，也不具有高度影响重要性（一般重要）。

# 股东会

股东会是公司的最高权力机构，分为年度股东会和临时股东会。年度股东会每年召开一次，于上一会计年度结束后的6个月内举行，临时股东会不定期召开。2025年召开股东会会议5次，审议通过议案20项。

# 董事会

公司董事会拥有公司日常事务的决策权。董事会分为定期会议和临时会议。定期会议每年至少召开两次会议，由董事长召集并主持。2025年召开董事会会议15次，审议通过补选董事、董事会换届选举、资产置换和定期报告等59项议案。

董事会下设战略委员会、审计委员会、提名委员会、薪酬与考核委员会四个专门委员会。专门委员会成员全部由董事组成，其中审计委员会、提名委员会、薪酬与考核委员会中独立董事占多数并担任召集人，审计委员会中有1名独立董事是会计专业人士。

# 战略委员会

主要负责对公司长期发展战略和重大投资决策进行研究并提出建议。

# 减少污染物排放

公司切实履行环境保护主体责任，严格遵守《中华人民共和国环境保护法》《中华人民共和国大气污染防治法》等相关法规，依照《固定污染源排污许可分类管理目录（2019年）》完成登记类管理排污许可；在河北省污染源环境管理数据平台和全国排污许可证管理信息平台公开污染物排放信息、污染防治设施建设和运行情况等信息。报告期内，公司污染物排放均达到国家标准和河北省标准，未发生环境纠纷和环境污染事故。

![](images/3dc5ea76af3db91881ca28fbdffe11fdf1e476fe0f848a9a775167d7b156fb5f.jpg)

- 公司日常运营产生的废弃物包括无害废弃物和有害废弃物，其中无害废弃物包括生活垃圾、餐厨垃圾、废纸、废塑料、废金属等，有害废弃物包括办公营业场所报废的墨盒、日光灯管等设备，以及机房废弃的裸露线路板、蓄电池等。  
- 严格推行废弃物分类处理，生活垃圾分类处理并移至指定位置，餐厨垃圾由具有回收处置资质的单位回收、处理。  
- 有害废弃物选择具备环保部门核发资质的废旧物资回收商处置，落实回收记录与备案，确保废弃物合规处置。

![](images/6d04ad917a4c9c978d84b7bc9ebc9e3568c8ae5c9194891e8664a42a51463512.jpg)

- 生产、生活废水经处理达标后接入正定新区污水处理厂，符合《污水综合排放标准》三级标准及污水处理厂进水要求。  
- 建有污水处理站，相关运行维护记录填写完整规范，切实保障污染防治设施稳定有效运转。

![](images/40c2c0ca028baa6c73f06e45c75551c897fce7474cc50bbce9fc08e0b7f0be70.jpg)

\- 编制重污染天气应急响应操作方案，实行“一厂一策”管理，科学制定应急减排措施，提升应对重污染天气的能力，降低极端天气下企业生产对环境造成的影响。

# 加强 水资源管理

公司严格遵守《中华人民共和国水法》及相关节水条例，使用智能感应水龙头，定期对水龙头、阀门等用水设备检修更换；开展节水宣传、张贴节约用水标识等；探索水资源循环利用途径，持续降低单位业务量的水资源消耗。

# 践行循环经济

公司积极践行循环经济发展理念，将资源节约与循环利用深度融入全流程运营管理。围绕电子设备、办公设施、包装材料等各类物资，大力推进分类回收再生，持续提升资源利用效率；同时深化数字化办公转型，依托办公自动化系统推行无纸化办公模式，严格落实必要文件双面打印、非必要文件线上传阅与电子归档等举措，最大限度降低资源消耗与废弃物产生，助力绿色低碳运营。
