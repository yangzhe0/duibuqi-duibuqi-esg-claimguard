# ◇ 铁轨为卷 绿美作答

铁轨延伸到哪里，责任就落在哪里；人与青山两不负，便是我们走向未来的方式。

# 把责任与未来，刻在铁轨之上

铁轨延伸处，皆是责任；车轮向前时，皆系民生。我们该把怎样的责任与未来，镌刻在铁轨之上？这一问题，既是西部创业对时代的深沉叩问，也是我们每一天用行动写下的实干答案。

2025年，极不平凡、极不容易、极为难忘。我们在变局中坚守主业，在攻坚中锤炼韧性，在担当中实现跨越。置身行业转型与区域发展的时代浪潮，我们始终高擎可持续发展之炬，自觉与国家同心、与区域同频、与生态共生、与员工同行。

面对复杂的外部环境和艰巨的改革发展任务，我们坚持以习近平新时代中国特色社会主义思想为根本遵循，深学笃行习近平总书记考察宁夏重要讲话精神，将可持续发展理念深度融入发展全局，旗帜领航、干在实处、走在前列。

我们深知：一条有担当的铁轨，不仅承载能源物资的流动，更丈量着企业对时代的承诺。这一年，我们统筹安全与发展、效益与责任，一体推进能源保运、提质增效、改革创新、绿色发展，以实干为笔，以担当为墨，在时代的答卷上，一笔一画写下属于西创的回答。

# 业务概况

公司坚持主业为锚、多元协同，始终专注于铁路运输与物流服务领域，业务核心为铁路运输，并协同发展铁路物流及相关多元业务。

# |主营业务

铁路运输是公司的核心业务与主要收入来源。公司依托宁东铁路等关键线路，承担区域内及跨区域的能源、原材料等大宗货物的铁路运输任务，为宁东能源化工基地及周边企业提供高效、稳定、绿色的铁路物流通道，全力保障区域能源供应链安全与畅通。

# 经营范围

经依法登记，公司的经营范围涵盖以下领域：

- 核心业务板块：铁路开发建设与经营管理；铁路专用线的代运营、代维修服务；仓储及物流服务；机车与车辆维修。  
- 能源与新兴业务板块：新能源项目的投资、建设、运营及技术服务；转供电、转供水业务。  
- 综合配套板块：酒店管理及住宿、餐饮服务（限分支机构经营）；高新技术产品的开发、生产与销售。  
- 传统与衍生业务板块：农副产品的种植、加工与销售；动植物的养殖、种植、加工与销售；食品、日用化工产品（不含易制毒及危险化学品）、酒的开发、生产和销售。

# 铁路运输板块

公司主要从事铁路开发建设与经营管理、仓储物流、机电及车辆维修等业务，核心任务是保障宁东能源化工基地的煤炭、油品、建设物资、化工原料及产品的运输需求。  
公司铁路西接包兰铁路大坝站，东连太中银铁路银川联络线梅花井站，北通内蒙古三新铁路上海庙站，形成了以古窑子站、鸳鸯湖站为中心、具备三个外运出口的地方铁路网络，为区域能源供应链的畅通与稳定提供了有力支撑。

# 铁路物流

作为公司铁路运输产业链的延伸与重要补充，公司以大宗货物铁路运输为核心，依托公铁联运、集装箱多式联运及铁路物流园运营，大力推进疆煤、蒙煤“进宁”及宁东基地煤化工产品外运供应链业务。  
在国铁、地方铁路、铁路物流园与铁路专用线之间，公司系统开展煤炭、煤化工产品、铁矿石等大宗货物的物流业务，构建起多节点联动、多方式协同的物流服务网络。

# 深度阅读

公司前身——广夏（银川）实业股份有限公司，于1994年2月18日依法设立，同年6月17日在深圳证券交易所上市，是宁夏回族自治区较早的上市公司之一。

2015年11月20日，公司取得中国证券监督管理委员会《关于核准广夏（银川）实业股份有限公司向宁夏国有资本运营集团有限责任公司等发行股份购买资产的批复》（证监许可〔2015〕2646号）；2016年2月向宁夏国有资本运营集团有限责任公司、国家能源集团宁夏煤业有限责任公司（原神华宁夏煤业集团有限责任公司）、中国信达资产管理股份有限公司、国家电投集团宁夏能源铝业有限公司、华电国际电力股份有限公司等5家股东发行股份，购买其合计持有的宁夏宁东铁路股份有限公司100%股权，完成重大资产重组。

2016年5月，公司名称正式变更为“宁夏西部创业实业股份有限公司”，证券简称变更为“西部创业”，证券代码000557。

重组完成后，公司主营业务由高新技术产品、农业开发等，转型为铁路运输与能源物流，开启了服务宁夏、深耕主业的全新发展阶段。

# ◇ 双重重要性分析

责任重点在哪里，资源就投向哪里。我们聚焦“财务重要性”与“影响重要性”两大维度，系统评估、排序、筛选可持续发展议题。不是为评估而评估，而是为了把每一份力，都用在最该用的地方。

分析路径如下：

1. 背景研究：通过行业调研识别与公司相关的重大趋势，结合公司业务特点、国家政策导向及资本市场关注要点，初步识别潜在议题。  
2. 议题清单：与管理人员、内外部专家、直属单位、员工、客户、供应商等利益相关方深入沟通，充分了解各方对重要性议题的意见，识别影响、风险与机遇，汇总形成议题清单。  
3. 评估确认：综合开展财务重要性评估与影响重要性评估，同时结合国家政策、资本市场关注要点及同业表现，生成重要性议题分析结果。  
4. 形成报告：汇总分析流程、方法及结论，向公司管理层进行汇报，确认本报告重点披露内容，明确未来可持续发展管理的工作目标与实施计划。

# ◇ 议题重要性分析结论

科学评估，是为了把力气花在最该花的地方。

报告期内，公司识别出22项重要性议题，其中5项为财务重要性议题，14项为影响重要性议题。哪些议题关乎生存底线，哪些议题影响长远价值——我们用双重重要性这把尺子，来一一丈量。

# | 生物多样性保护

# I 优化生产用能结构

以宁东铁路电气化改造为核心，项目总投资约18.1亿元，我们加快线路、通信、信号、电力及机车车辆升级迭代，推进营业线道口拆并改，实现轨道装备重型化、养路机械化、用能绿色化。同步优化运输组织方案，通过精细化调度指挥减少机车无效停留，提升机车运用效率，降低燃油消耗与废气排放。每一滴油，都用在刀刃上。

在能源使用管控方面，我们严格把控燃油品质，在内燃机车、作业机械全面推广合格燃油，升级尾气净化装置，持续消除超标冒黑烟现象。同时，推进货场、物流园作业车辆与移动机械新能源化，降低传统燃油设备使用比例，推动能源结构向清洁低碳转型。

# ◇ 守护健康安全

# 治理

安全是回家的路，健康是奋斗的底。我们始终将员工生命安全与职业健康放在首位，制定实施《安全生产工作规定》《高风险作业管理办法》等18项安全规章制度，持续夯实安全管理根基。

我们严格推行 “三现管理” （现场、现实、现在）工作法，提升现场管控效能。逐级签订安全生产 “两个清单” 与消防安全承诺书，层层压实主体责任，构建上下联动、齐抓共管的责任体系。安全，不是一个人的事，是每一个岗位、每一道工序的共同坚守。

制度，不是摆设，是每一条生命背后的护栏。我们构建全方位、多层次的安全生产治理体系，将安全生产纳入“第一要务、第一议题、第一课”，确保安全工作在决策层面优先。结合实际制定年度安全环保工作目标与要点，细化重点任务清单，明确时限与责任，让每一项部署都能落地生根。

宁东铁路制定实施《职业健康管理制度》等制度，持续完善职业健康专业化管理，积极开展职业病防治宣传教育与专项培训。让员工懂得保护自己，是企业最实在的关怀。从制度到意识，从防护到习惯，守护健康安全，就是守护每一个家庭的完整。

# 晋升机制

晋升不是“熬年头”，是让每一份能力找到坐标。

我们构建长期、阶段与年度相衔接的人才管理体系，打造经营管理、专业技术、高技能三支核心队伍。制定《三支队伍建设三年行动计划》《职业发展管理办法》《职位职级核定方案》等制度，从顶层设计上为人才梯队建设确立方向。

薪酬与职级挂钩。建立动态宽带薪酬体系，薪酬向绩优人员倾斜。总部设13级39档，分管理类（M）、专业技术类（T）、技能类（S），三类互通。M/T类设1-16级，S类设1-13级。这不是一张薪酬表，而是一张成长地图——“我在哪里”“能往哪里去”。

# 反不正当竞争

# 商业宣传

严守真实性原则，杜绝虚假或引人误解的内容。每一句宣传，都对得起事实；每一次推广，都经得起追问。

以高质量服务为核心竞争力，尊重每一位对手。不编造、不传播虚假信息，不做混淆商誉的行为。行业生态，靠大家一起维护。

# 反垄断合规

不达成垄断协议，不滥用市场支配地位，不进行差别待遇。公平交易，是法治的要求，也是我们对市场规则的敬畏。
