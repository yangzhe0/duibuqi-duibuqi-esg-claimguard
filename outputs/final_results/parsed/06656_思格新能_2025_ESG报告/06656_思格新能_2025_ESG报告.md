# 董事會聲明

![](images/def7440ad47b2cda2e005f959d7b14a416f90467d22227728d782114110da42b.jpg)

66

2025年，思格新能源在持續深耕新能源領域的同時，進一步將可持續發展推向縱深。面對全球綠色低碳轉型的浪潮與日益嚴格的可持續治理要求，本公司堅持以推動可持續未來為己任，將ESG理念全面融入戰略決策與日常營運。我們深信，卓越的ESG管理不僅是企業應對波動、實現長期價值增長的基石，更是對利益相關方的一份堅實承諾。

22

公司已建立由上而下的ESG管治架構。董事會作為最高責任機構，負責審視可持續發展趨勢，監督重大相關議題並識別發展機遇，指導制定公司的ESG願景、目標、策略與架構，以確保戰略的前瞻性與科學性。

董事會將可持續發展深度融入企業戰略，透過研判宏觀政策、結合內部規劃、吸納利益相關方溝通回饋等方式，對ESG議題及相關風險進行識別、排序與管理，從而明確治理重點與管理策略，持續推動ESG工作的落實與優化。在報告期內，董事會透過問卷調查等形式，積極參與實質性議題的評估與排序，就影響公司長期發展的ESG議題提出觀點與建議，並審定其優先級。詳情請參閱本報告「可持續發展治理—實質性議題評估」章節。

董事會持續加強對ESG治理的監督與參與，設立了與業務緊密關聯的年度環境目標，並對目標設定進行審閱討論，同時對上一年度環境目標的完成情況進行了檢討。

本ESG報告披露思格新能源在2025年的ESG工作進展與成果，已於2026年4月25日獲得董事會審閱並批准發布。

# 環境績效

- 節能降耗顯著：核心產品能效提升突出，逆變器單位產品綜合能耗（kWh/台）同比下降54%，Pack單位產品綜合能耗（kWh/台）同比下降47%，充電樁單位產品綜合能耗（kWh/台）同比下降64%。  
- 潔淨能源應用：購買綠電15,000兆瓦時，為碳中和目標貢獻積極力量。  
- 循環經濟實踐：積極響應歐盟PPWR法規²，推進包裝「去塑化」，大部分戶用產品已完成紙製包裝替換。

![](images/6e1ae593a99929d34c709c01206d09d26286026731885080e2aacdb23c4b21fb.jpg)

# 社會績效

- 數智化製造：打造「AI+光儲充」智能工廠，實現全流程數字化製造管理100%覆蓋。  
- 品質匠心保障：產品製造良率穩定保持在99%以上，工商業儲能系統SigenStack成功通過極端火燒測試，安全性能領先。  
- 客戶服務提質：推出SigenCare智能服務體系，一套融合主動維護與AI防護技術的終身服務體系。  
- 人才培養體系：啟動首屆中基層管理者發展項目，覆蓋60名管理骨幹，系統提升管理實戰能力。  
- 供應鏈減碳：公司積極優化產能布局，項目落實後單次運輸距離將減少1,438公里，助力低碳供應鏈提升。

![](images/80629bc7a9a22121452b28ea2b2ebd56bfbd99b9f645cb432a7d4a72ce5ecd6d.jpg)

# 管治績效

- 治理架構多元化：董事會構成多元均衡，女性董事佔比達37.5%，獨立董事佔比37.5%，下設三大專業委員會，切實保障決策的科學性與獨立性。  
- ESG管理體系：搭建「董事會－可持續管理委員會－可持續工作小組－各業務職能部門」由上而下的四級ESG治理架構，明確各部門職責，實現ESG工作層層落實、閉環管理。  
- 資訊安全認證：通過資訊安全管理體系認證，設立首席數據保護官，建構完善的資訊安全與私隱保護防線。

# 企業簡介

![](images/2d16c3d6c979d81b410518fc7803089d4ad42d6e8378d2734b3517f2f263e494.jpg)

思格新能源成立於2022年，總部位於上海，是一間專注於新能源領域的科技創新企業。公司憑藉全球領先的數字智能技術與高質素創新人才團隊，深度布局光伏發電、智慧儲能及高效電動車（EV）充電領域，致力為全球家庭及企業客戶提供安全、智能、高效的「光儲充」一體化產品與全場景智慧能源解決方案。

圍繞新能源產業規模化、高可靠應用的發展需求，我們堅持以「極簡部署、極致安全、極佳體驗」為核心理念，通過系統級技術創新，持續提升產品與解決方案的安全性、可靠性及智能化水平。截至2025年底，公司業務覆蓋全球85個國家和地區的172家分銷商達成深度戰略合作，在亞太、歐洲及非洲等主要市場均已成為頭部渠道夥伴的首選品牌。

# 治理架構

思格新能源嚴格遵循《中華人民共和國公司法》《中華人民共和國證券法》《香港聯合交易所有限公司證券上市規則》等相關法律法規及監管要求，致力於建構權責清晰、運作透明、制衡有效的治理體系，以保障利益相關方的合法權益，推動公司實現長期、穩健、可持續發展。

公司嚴格遵循《公司章程》及相關規定，規範股東會的召集、召開流程與議事程序。股東會作為公司最高權力機構，充分保障股東合法權益，切實保障股東行使發言權、表決權，確保股東可對公司經營活動進行有效監督。

董事會為公司經營決策機構，由8名董事組成，包括執行董事、非執行董事及獨立非執行董事，其中獨立非執行董事佔比不低於三分之一，以切實提升公司治理的獨立性、客觀性與專業水準。董事會下設審計委員會、提名委員會及薪酬委員會等專門委員會，各委員會依據公司章程及董事會授權履行職責，並將其審議意見或提案提交董事會作出最終決策。

# 董事會

# 審計委員會

主要負責提議聘任或更換外聘審計師並監督其獨立性與表現，審查公司財務資料及報告並提供意見，評估內部控制有效性、監督ESG政策實施與整體表現，協調管理層、內部審計部門及外部審計機構的溝通。

# 提名委員會

主要負責就董事會規模及組成提出建議，研究制定董事、總經理及高級管理層的選舉標準與程序，審查董事會候選人及高級管理層人選，評估及審核獨立非執行董事的獨立性。

# 薪酬委員會

委員會由三名董事組成並設主席一名，主要負責制定董事、監事及高級管理層的個別薪酬方案，審查其績效評估標準並開展年度評估，監督薪酬計劃落實，審批股份計劃相關事項。

同時，公司積極建構專業、多元包容的董事會，已制定並實施董事會多元化政策，透過綜合考量性別、年齡、文化背景、教育及專業經驗等維度，推動董事會知識結構與能力組合的均衡配置。目前董事會由3名女性董事與5名男性董事組成，已達成性別多元化目標，專業領域覆蓋能源、金融、企業管理及管治等多個方向。提名委員會承擔監督職責，將定期審查政策有效性、制定並跟進可量化實施目標。公司每年在企業管治報告中披露相關進展，持續推進董事會及高級管理層等全層級的多元化建設，以提升整體治理效能。

# - 薪酬政策

思格新能源對董事及高級管理層的薪酬，採取了結構多元、與績效緊密掛鉤的管理方式。薪酬主要包括固定部分的薪金、津貼與實物福利，以及浮動部分的績效獎金。此外，公司透過股權激勵及退休金計劃供款，建構長期激勵機制。是公司綜合考慮經營業績、市場可比先例及主要經營指標達成情況等因素制定的薪酬水平，旨在實現激勵與約束的平衡，確保薪酬政策與公司長期發展目標及股東利益保持一致。

# 風險管理

思格新能源致力於將全面風險管理理念融入公司治理和經營管理的各個環節，通過建立健全的風險管理體系、嚴密的內部控制機制以及嚴格的合規管理制度，實現風險的及時管控。

# - 風險管理體系

公司內部制定《思格內部審計管理制度》《思格全面風險管理辦法》等風險管理相關制度，明確風險識別、評估、監控與應對的全流程規範。同時，建構了涵蓋董事會、經營層等多層級在內的全面風險管理架構，確保各部門及全體員工樹立風險防範意識，推動公司穩健營運。

# 第一道防線

# 各業務部門

- 作為風險管控的前端主體，負責日常業務全流程風險識別、提出重大風險應對策略及具體應對方案；  
- 落實具體風險防控措施，及時上報風險隱患；監控風險事件的變化狀態、填報關鍵指標數據，適時制定和啟動應急預案，承擔風險管控的首要責任。

# 第二道防線

# 流程與效率部、財務部及法務部

- 主持全面風險管理的日常工作，組織開展年度風險評估及應對工作，負責對評估結果匯總分析，對其他部門和分支機構開展的專項業務風險評估提供指導和支持；  
- 對重大風險應對方案的制定、執行和效果情況進行監督檢查；協調解決跨部門重大風控問題；組織風控培訓與推廣；建立全流程監控機制，確保數據真實、完整、可追溯。

# 第三道防線

# 審計部

- 作為獨立監督主體，對各部門的主要風險點進行獨立的日常監控與管理、對各部門的運行過程和結果進行獨立的稽核與檢查；  
- 開展風險管理體系有效性審計與監督檢查；評價風險識別、控制與應對措施的執行效果，跟蹤內控缺陷整改，保障風險管理閉環運行。

# - 重點風險防控

結合新能源行業的發展特點與公司當前經營實際，思格新能源建構了系統性的風險分類與管理體系。公司全面識別並界定了管理、聲譽、道德、信用、操作、合規及市場等七大類風險，明確了每類風險的定義與邊界，為實施精準、前瞻的風險管控奠定了基礎。

在管理策略與執行上，公司建立了由審計委員會審定、董事會審批、管理層落實的閉環治理機制，並依據內外環境變化進行動態調整。透過每年度的全面風險評估，以及內部審計/覆核、與第三方突擊檢查相結合的多維度排查機制，公司能夠持續、深入地識別營運與管理中的潛在風險，確保風險得以及時發現與有效控制。

公司建立了風險發生後的分級回應與閉環處置機制。風險發生後，立即啟動相應的控制與減緩措施，透過落實內控控制措施、動態追蹤風險態勢等方式，有效控制並減緩風險擴散與影響程度。同時深挖風險根源，透過優化制度流程、整改內控缺陷等舉措從源頭消除風險隱患。在此基礎上開展事件覆盤、責任認定與整改落實，同步完善責任追究與損失追償機制，持續提升公司風險防控的韌性與有效性。報告期內，公司未發生重大風險事件，風險防控體系運作有效，經營保持穩健可控。

# - 廉潔管理

# - 廉潔培訓

公司將反腐敗及反舞弊內容納入新入職員工培訓的核心課程，實現廉潔教育由入職開始全面覆蓋，並每年組織一次全員反腐敗反舞弊專項宣傳培訓及考核，反覆強調廉潔誠信的重要性，持續深化全體員工的廉潔從業意識。

# 隱私保護

公司嚴格遵循合法、正當、必要的原則，對員工、客戶及合作夥伴的個人資料實施全生命週期合規管理。為強化個人資料保護治理能力，制定《數據保護官（DPO）制度》，並設立首席數據保護官（DPO），統籌協調個人資料處理相關工作。DPO在事前實時分析潛在安全風險，及時發現隱患；事後迅速採取補救措施減少損失，並總結檢討以防止同類問題再次發生，形成閉環式的隱私風險管理機制。

隨著公司業務全球化拓展，數據跨境場景日益增多，對跨境數據合規與隱私保護提出更高要求。我們嚴格遵循《歐盟通用資料保護條例》（GDPR）等國際隱私法規要求，系統識別並適配核心業務所在地國家的資料保護法律，確保數據處理活動在全球化布局中符合當地法律規定，切實保障數據主體的合法權益。

公司制定《數據安全事件回應管理辦法》，一旦發生隱私洩露，應急回應小組將立即開展事件排查、影響分析與風險評估，按等級實施管控處置，快速阻斷洩露並消除風險。DPO負責評估監管上報與主體告知義務，依法向監管部門報備，並以適當方式通知受影響個人，說明事件情況、應對措施及防範建議。事件處置完成後，公司及時開展覆盤整改，優化制度流程，防止同類事件復發。報告期內，公司未發生隱私洩露事件。

# 治理

為指導可持續發展策略的規劃與制定，有效統籌與監控可持續發展績效目標的達成，2025年思格新能源制定《可持續發展和ESG管理》，將氣候相關議題的監督與責任融入最高決策層，指導公司各級組織有序開展應對氣候變化工作。有關公司氣候變化治理架構的詳細資訊，請參閱本報告「可持續發展管理—實質性議題評估」章節。

公司董事會及可持續發展管理委員會依託現有治理架構，統籌開展氣候相關風險與機遇的識別、評估與監督管理工作，並將持續完善適配公司發展階段的氣候監督能力，推動氣候相關因素與公司整體治理、策略及風險管理工作深度融合。

同時，我們正持續完善氣候相關數據收集與管理體系，穩步推進氣候目標設定、進度監控及相關機制建設。鑑於當前氣候相關管理工作仍在有序推進中，部分定量資訊與細化流程尚在完善，公司將根據工作進展及監管要求，及時更新披露相關內容。

# 戰略

思格新能源積極響應中國「雙碳」目標，對標聯合國可持續發展目標，持續推動自身綠色發展和潔淨生產，不斷加強氣候相關資訊監控與披露，以提高自身營運的氣候韌性。同時，公司攜手價值鏈上的合作夥伴，深化在可持續發展方面的協同合作，促使其採取適當行動提升氣候變化應對能力，從而帶動價值鏈的可持續轉型，以共同應對氣候變化。

2025年，公司在政策研究、外部環境分析的基礎上，全面識別、評估氣候變化相關風險與機遇對公司業務發展的潛在影響。公司採用定性分析方法，物理風險分析主要參考聯合國政府間氣候變化專門委員會（IPCC）氣候情景框架，轉型風險分析主要參考綠色金融網絡（NGFS）的氣候情景框架，為公司科學決策提供依據。

# 風險管理

2025年，思格新能源正積極推進將氣候相關風險與機遇全面納入公司風險管理。在此過程中，公司積極探索將氣候風險的識別、評估與現有風控流程相結合，將氣候目標與公司策略對接，以促進氣候管理與全面風險管理的有機融合。

# 指標及目標 $^{9}$

公司重視氣候變化應對與低碳發展相關工作，遵循監管要求與業界實踐，持續完善氣候相關管理與資訊揭露機制，穩步推進環境責任落實，助力公司可持續發展。

目前，公司正結合產業發展趨勢與營運實際，積極推進中長期低碳發展目標建設，系統性編制中長期溫室氣體減排規劃。同時，積極完善範圍三溫室氣體排放核算體系，全面釐清全價值鏈排放底數。為確保減排目標的科學性、可執行性與核算口徑一致性，公司將在完成長期策略梳理及全範圍排放底數釐清後，統一揭露下一階段減排目標與實施路徑。

# 環境管理體系

思格新能源建構涵蓋合規管理、風險防控、應急響應與環保教育的全方位環境管理體系，不僅確保生產經營活動的環保合規與風險受控，更將綠色理念深度融入公司營運基因，持續提升公司環境治理能力與可持續發展韌性。

# - 健全合規管理

公司嚴格遵守《中華人民共和國環境保護法》等法律法規，制定《環境保護管理規定》，設立EHS部門專職負責環境合規工作，系統維護《環保設施運行記錄表》《巡查記錄表》及《月度檢查記錄表》等記錄，推動環保工作規範化、高效化開展。公司已建構完善的環境管理體系，公司總部及金橋生產園區、臨港生產園區均已通過ISO 14001環境管理體系認證。

# - 強化風險防控

公司在新項目建設中全面建構起「識別－防範－應急」三位一體的環境風險防控體系，致力於在風險發生前主動化解、在隱患形成前及時消除，全面築牢公司環境風險防控屏障，為可持續發展提供堅實保障。

# 開展環境風險識別

\- 識別主要危險物質、可能影響途徑以及可能受影響的敏感目標。

# 採取風險防範措施

\- 嚴禁明火，危險品與危險廢物按規定規範存放管理，且所有涉危單元均已實施防滲處理。

# 持續完善應急機制

- 在庫房、生產廠房各危險單元內配置吸附棉、防毒面罩、滅火器等應急物資，並定期檢查危廢倉庫。  
- 依照《企業事業單位突發環境事件應急預案備案管理辦法（試行）》等相關規定，系統編制突發環境事件應急預案。  
- 要求工作人員持證上崗，在日常生產營運中對操作人員進行培訓，降低因人員操作失誤導致化學品洩漏的可能性，並定期開展應急演練。

# 全流程品質管理

思格新能源遵循「事前預防、事中管控、事後追溯」原則，建構涵蓋研發、製造、交付到售後的全鏈條閉環管理體系，確保產品高可靠、高安全、可信賴。

# - 研發品質

公司已建立健全的產品開發品質全流程體系，包含技術評審、決策評審、需求管理、變更管理等流程規範。在方案設計初始階段，即開展DFMEA分析與核心品質排查，同步梳理歷史問題；設計過程中通過多輪設計評審，前置識別技術風險與品質隱患；技術評審環節設置多階段品質門控點，涵蓋從需求方案鎖定到量產交付的核心節點，通過問題跟蹤整改形成技術品質閉環；決策評審環節圍繞市場商業、技術方案、供應鏈保障等多維度開展階段評估，為項目推進提供科學決策依據。

該體系透過全流程規範約束與前置防控，實現研發品質的系統性管控。從設計源頭的品質排查，到過程中的評審閉環，再到階段決策的雙重校驗，形成涵蓋需求、設計、評審、決策的完整品質防線，有效防範研發風險，保障產品從研發到量產的高效、高品質落實。

思格新能源將環境責任、社會責任與商業道德深度融入供應商准入、合作、評估、優化的全生命週期，推動供應鏈生態持續健康發展。同時，公司將積極推動供應鏈可持續管理的細化量化，強化人權與強迫勞動風險識別，結合高風險地區業務特點優化本地化策略，進一步提升供應鏈韌性與合規水平。

# - 管理體系

思格新能源以風險導向、分級管理為核心原則，構建全流程供應商管控體系，保障供應鏈穩定、合規與高效運轉。准入環節實施差異化審核機制，嚴格核查資質、技術、品質、交付及供應鏈管理能力，從源頭篩選合格合作夥伴。

為推動供應商綜合能力持續提升，公司建立標準化績效評價機制，制定《供應商績效考核》《供應商審核機制》等制度，圍繞品質、交付、成本、服務及技術回應等維度，開展月度評分、季度與年度綜合評級。

公司依據評價結果實施分級獎懲與動態管理，對年度A級優秀供應商予以激勵，並在戰略項目中給予獎勵份額傾斜。對季度D級供應商開展整改督導，評估下調供貨份額。對年度D級及整改後仍不達標供應商，及時啟動份額調整、替代方案與退出流程，形成准入、管控、提升、退出的完整閉環，保障供應鏈長期合規、高效與可持續發展。

# - 行為準則

公司制定《供應商行為準則》，明確要求所有合作夥伴在合規用工與勞動保障、環境保護、商業誠信、衝突礦產禁用等方面履行基本責任，共同推動社會、環境與道德的持續進步。同時，出台《供應商CSR盡職調查管理規定》，要求供應商簽署《遵守上海思格源供應商行為準則的聲明》，強化供應鏈社會責任管理。針對供應商違反CSR紅線 $^{23}$ 的行為，公司已建立處置機制：若後續發現供應商存在嚴重違規情形，將立即暫停合作，並發出《糾正/預防措施要求表》，全程跟蹤整改成效。

![](images/4c0793c4e81697313110590f9275243bdfb03b0575815342792b88cec9b3ca32.jpg)

案例

2025年6月，公司在保加利亞舉辦「模組化儲能解決方案交流會」，其高效、靈活的技術方案獲得保加利亞國家電網調度中心高度評價。項目共部署90套模組化儲能系統，總容量達20MWh。依托創新的模組化堆疊結構與浮插式端子連接技術，系統無需吊裝設備、無需複雜布線，僅由5人團隊在10天內完成全部安裝，2天完成調試，並於並網當日20分鐘內實現20MWh全容量成功投運。

# 工作摘要

我們的鑑證程序包括但不限於以下內容：

1. 管理體系及流程的了解與評估：

\- 審閱用於生成、匯總及報告選定資料的相關系統與流程；

\- 執行分析性程序，以評估所披露數據的一致性及合理性。

\- 對選定營運場所進行現場訪問，觀察數據收集及報告流程；

\- 評估相關披露與既定報告編製依據的一致性。
