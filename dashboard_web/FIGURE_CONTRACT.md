# Dashboard Figure Contract

## 核心结论

交互式看板必须清楚区分“自动运行状态”和“人工标注评价”，并让每一条结构化结果能够回到 PDF 原文证据。

## 证据链

1. 系统总览：展示 200 份报告、65 个指标和 13000 个任务的规模，不解释为准确率。
2. E/S/G 分布：展示各维度的 `found` 数量，说明披露证据分布。
3. 指标类型分布：区分 quantitative、qualitative 与 boolean 的运行结果。
4. 证据工作台：通过 PDF 页码和 bbox 高亮证明结构化结果可追溯。
5. 质量评测：仅用人工复核样本计算 Precision、Recall 和 F1。

## 视觉语义

- 深绿色：系统主流程、可信状态和 E 维度。
- 蓝色：S 维度与中性信息。
- 金色：证据定位、G 维度和需要关注的提示。
- 红色：错误与高风险，不用于普通装饰。
- 灰色：缺失、未复核及辅助信息。

所有统计图均保留数值标签，不依赖颜色单独传递结论；红绿颜色不作为唯一状态编码。
